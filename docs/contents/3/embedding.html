14  Graph and Manifold Embedding

PCA represents data with a linear subspace. This is effective when the important geometry is approximately linear, but it may miss curved or connectivity-based structure.

Graph and manifold methods begin from a different idea: nearby observations should remain nearby after embedding. A common workflow is

\[ \text{features} \longrightarrow \text{neighborhood graph} \longrightarrow \text{low-dimensional coordinates} \longrightarrow \text{visualization or clustering}. \]

This chapter studies spectral methods, Isomap, self-organizing maps, t-SNE, and UMAP. These methods have different algorithms, but all replace the original coordinates with a representation designed to preserve selected geometric or neighborhood structure.

14.1 From Data to a Graph

Treat each observation as a vertex. An edge between observations \(i\) and \(j\) records that they are similar. The weighted adjacency matrix is

\[ W=\mqty[W_{ij}], \qquad W_{ij}\ge 0. \]

Two common constructions are:

  • a \(K\)-nearest-neighbor graph;
  • a kernel graph, such as

\[ W_{ij} = \exp\qty( -\frac{\norm{x_i-x_j}^2}{2\sigma^2} ). \]

The graph determines the geometry that the method sees. A small neighborhood emphasizes local structure; a large neighborhood moves toward global Euclidean structure.

CautionPreprocessing still matters

Neighborhoods are computed from a distance or similarity. Scaling, irrelevant features, missing-value handling, and the metric can change the graph before the embedding algorithm begins.

14.2 Spectral Clustering

K-means partitions observations by proximity to centers. Spectral clustering instead partitions a graph by connectivity. It is useful for non-convex groups such as rings, curves, and linked regions.

14.2.1 Graph Laplacian

Define the degree matrix

\[ D=\diag(d_1,\ldots,d_n), \qquad d_i=\sum_{j=1}^nW_{ij}. \]

The unnormalized graph Laplacian is

\[ L=D-W. \]

For any vector \(f\in\mathbb R^n\),

\[ f^\top Lf = \frac12\sum_{i=1}^n\sum_{j=1}^n W_{ij}(f_i-f_j)^2. \]

This identity explains the method. If two vertices have a large edge weight, the quadratic form penalizes assigning them very different values. Smooth eigenvectors of \(L\) therefore provide coordinates that respect graph connectivity.

A common normalized Laplacian is

\[ L_{\mathrm{sym}} = I-D^{-1/2}WD^{-1/2}. \]

Normalization reduces the influence of vertices that have unusually large degrees.

14.2.2 Spectral Clustering Algorithm

For \(K\) clusters:

  1. construct an adjacency matrix \(W\);
  2. compute a graph Laplacian;
  3. take eigenvectors associated with the \(K\) smallest eigenvalues;
  4. use their rows as an embedded representation of the observations;
  5. apply K-means to the embedded rows.

The final step is ordinary K-means, but it operates in graph-derived coordinates rather than the original feature space.

14.2.3 Concentric Circles

import numpy as np
import matplotlib.pyplot as plt

from sklearn.datasets import make_circles
from sklearn.cluster import KMeans, SpectralClustering
from sklearn.preprocessing import StandardScaler

X_circle, y_circle = make_circles(
    n_samples=600,
    factor=0.45,
    noise=0.05,
    random_state=1,
)

kmeans = KMeans(n_clusters=2, n_init=20, random_state=1)
kmeans_group = kmeans.fit_predict(X_circle)

spectral = SpectralClustering(
    n_clusters=2,
    affinity="nearest_neighbors",
    n_neighbors=10,
    assign_labels="kmeans",
    random_state=1,
)
spectral_group = spectral.fit_predict(X_circle)

fig, axs = plt.subplots(1, 3, figsize=(13, 4), sharex=True, sharey=True)

for ax, labels, title in zip(
    axs,
    [y_circle, kmeans_group, spectral_group],
    ["Underlying Structure", "K-Means", "Spectral Clustering"],
):
    ax.scatter(X_circle[:, 0], X_circle[:, 1], c=labels, s=16)
    ax.set_title(title)
    ax.set_xlabel("x1")
    ax.set_ylabel("x2")

plt.tight_layout();

14.3 Isomap

Isomap is a nonlinear extension of multidimensional scaling (MDS). Its main idea is that Euclidean distance can be misleading when observations lie near a curved manifold.

For example, two points on different layers of a rolled surface may be close in ambient Euclidean distance even though traveling along the surface between them requires a much longer path. Isomap estimates this geodesic distance with shortest-path distance on a neighborhood graph.

14.3.1 Isomap Algorithm

Isomap consists of three main steps:

  1. construct a \(K\)-nearest-neighbor or radius-neighbor graph;
  2. compute shortest-path distances between every pair of observations on the graph;
  3. apply classical MDS to the shortest-path distance matrix.

Let \(G_{ij}\) denote the graph shortest-path distance between observations \(i\) and \(j\). Classical MDS finds low-dimensional coordinates \(z_1,\ldots,z_n\) whose Euclidean distances approximate these graph distances:

\[ \norm{z_i-z_j}\approx G_{ij}. \]

Thus Isomap tries to preserve global distances measured along the manifold, rather than direct Euclidean distances through the ambient space.

14.3.2 Swiss Roll Example

from sklearn.datasets import make_swiss_roll
from sklearn.manifold import Isomap

X_roll, roll_position = make_swiss_roll(
    n_samples=1000,
    noise=0.05,
    random_state=1,
)

isomap = Isomap(
    n_neighbors=12,
    n_components=2,
)
X_isomap = isomap.fit_transform(X_roll)

fig = plt.figure(figsize=(12, 5))

ax1 = fig.add_subplot(1, 2, 1, projection="3d")
ax1.scatter(
    X_roll[:, 0],
    X_roll[:, 1],
    X_roll[:, 2],
    c=roll_position,
    cmap="viridis",
    s=8,
)
ax1.set_title("Swiss Roll")

ax2 = fig.add_subplot(1, 2, 2)
ax2.scatter(
    X_isomap[:, 0],
    X_isomap[:, 1],
    c=roll_position,
    cmap="viridis",
    s=8,
)
ax2.set_xlabel("Isomap1")
ax2.set_ylabel("Isomap2")
ax2.set_title("Isomap Embedding")

plt.tight_layout();

The color shows position along the roll and is used only to interpret the result. Isomap approximately unfolds the curved surface into two dimensions.

14.3.3 Choosing the Neighborhood

n_neighbors controls the graph used to approximate geodesic distances.

  • If it is too small, the graph may become disconnected and shortest paths may be unstable.
  • If it is too large, edges can create shortcuts across the manifold and Isomap approaches ordinary Euclidean MDS.
CautionWhen Isomap is unsuitable

Isomap assumes that meaningful global geometry can be recovered from shortest paths on a well-sampled manifold. It can be sensitive to noise, outliers, disconnected graphs, sparse sampling, and shortcuts between nearby folds.

14.4 Self-Organizing Maps

A self-organizing map (SOM) represents observations with prototypes arranged on a low-dimensional grid. Each grid location \(r\) has a prototype vector \(m_r\in\mathbb R^p\).

For an observation \(x\), the best matching unit is

\[ c(x)=\argmin_r\norm{x-m_r}. \]

During training, the winning prototype and its grid neighbors move toward the observation:

\[ m_r(t+1) = m_r(t) + \alpha_t h_{c,r}(t)\qty[x-m_r(t)], \]

where \(\alpha_t\) is a learning rate and \(h_{c,r}(t)\) decreases with grid distance from the winning unit.

The neighborhood width is usually large early in training and shrinks over time. Early updates organize the global map; later updates refine local prototypes.

14.4.1 What a SOM Produces

A fitted SOM gives:

  • a grid of prototype vectors;
  • the best matching grid cell for each observation;
  • a two-dimensional summary in which nearby cells tend to represent similar observations.

It combines aspects of vector quantization and topology-preserving visualization. Unlike PCA or UMAP, the output locations are restricted to a regular grid.

Python does not include SOM in core sklearn. One lightweight implementation is MiniSom.

uv add minisom
from minisom import MiniSom
from sklearn.datasets import load_wine
from sklearn.preprocessing import StandardScaler

rng = np.random.default_rng(1)

wine = load_wine()
X_wine = StandardScaler().fit_transform(wine.data)
y_wine = wine.target

som = MiniSom(
    x=10,
    y=10,
    input_len=X_wine.shape[1],
    sigma=1.5,
    learning_rate=0.5,
    random_seed=1,
)

som.random_weights_init(X_wine)
som.train_random(X_wine, num_iteration=3000)

winner = np.array([som.winner(x) for x in X_wine])

plt.scatter(
    winner[:, 0] + rng.uniform(-0.2, 0.2, len(winner)),
    winner[:, 1] + rng.uniform(-0.2, 0.2, len(winner)),
    c=y_wine,
    edgecolor="black",
)
plt.xlabel("SOM grid x")
plt.ylabel("SOM grid y")
plt.title("Wine Data on a Self-Organizing Map");

Jitter is added only to show observations assigned to the same grid cell.

CautionSOM output is exploratory

The map depends on grid dimensions, initialization, learning rate, neighborhood width, and training length. Grid adjacency is meaningful, but the precise Euclidean distance between two grid cells should not be treated as an exact original-space distance.

14.5 t-SNE

t-distributed stochastic neighbor embedding (t-SNE) is a nonlinear embedding method designed primarily for visualization. It converts high-dimensional distances into neighborhood probabilities and seeks low-dimensional coordinates with similar neighborhood probabilities.

Unlike Isomap, t-SNE does not try to preserve global pairwise distances. Its main goal is to place observations with similar local neighborhoods near one another.

14.5.1 Neighborhood Probabilities

For each observation \(i\), t-SNE defines a conditional probability that observation \(i\) would select observation \(j\) as a neighbor:

\[ p_{j\mid i} = \frac{ \exp\qty(-\norm{x_i-x_j}^2/(2\sigma_i^2)) }{ \sum_{k\ne i} \exp\qty(-\norm{x_i-x_k}^2/(2\sigma_i^2)) }, \qquad j\ne i. \]

The bandwidth \(\sigma_i\) adapts to the local density. The conditional probabilities are symmetrized to obtain high-dimensional similarities \(p_{ij}\).

For low-dimensional coordinates \(z_i\), t-SNE uses a heavy-tailed Student-\(t\) similarity:

\[ q_{ij} = \frac{(1+\norm{z_i-z_j}^2)^{-1}} {\sum_{k\ne \ell}(1+\norm{z_k-z_\ell}^2)^{-1}}. \]

The heavy tail helps moderately distant observations repel one another and reduces the crowding that occurs when many high-dimensional neighborhoods are represented in two dimensions.

t-SNE minimizes the Kullback–Leibler divergence

\[ \operatorname{KL}(P\Vert Q) = \sum_{i\ne j} p_{ij}\log\qty(\frac{p_{ij}}{q_{ij}}). \]

Because the divergence is asymmetric, failing to place true neighbors together is penalized more strongly than placing some unrelated observations too close together. This is one reason t-SNE emphasizes local clusters.

14.5.2 Digits Example

from sklearn.datasets import load_digits
from sklearn.decomposition import PCA
from sklearn.manifold import TSNE
from sklearn.preprocessing import StandardScaler

digits = load_digits()
X_digits = StandardScaler().fit_transform(digits.data)
y_digits = digits.target

# PCA initialization is stable and removes noisy directions before t-SNE.
X_digits_pca = PCA(n_components=30, random_state=1).fit_transform(
    X_digits
)

tsne = TSNE(
    n_components=2,
    perplexity=30,
    init="pca",
    learning_rate="auto",
    max_iter=1000,
    random_state=1,
)
X_tsne = tsne.fit_transform(X_digits_pca)

fig, ax = plt.subplots(figsize=(8, 6))
scatter = ax.scatter(
    X_tsne[:, 0],
    X_tsne[:, 1],
    c=y_digits,
    cmap="tab10",
    s=10,
    alpha=0.75,
)
ax.set_xlabel("t-SNE1")
ax.set_ylabel("t-SNE2")
ax.set_title("Digits t-SNE")
ax.legend(*scatter.legend_elements(), title="digit", ncol=2);

The class labels are used only for coloring. t-SNE is fit without the labels.

14.5.3 Perplexity

The main tuning parameter is perplexity. It is related to the effective number of neighbors used around each observation.

  • Smaller perplexity emphasizes very local structure and can fragment the embedding.
  • Larger perplexity incorporates broader neighborhoods and requires more observations.

The result also depends on initialization, learning rate, iteration count, and random seed. A useful interpretation should persist across several reasonable settings.

CautionInterpreting t-SNE

Distances between separated groups, group sizes, and empty space in a t-SNE plot do not generally have direct quantitative meaning. t-SNE may create visually distinct islands even when the original data vary continuously.

Standard sklearn t-SNE also does not provide a .transform() method for new observations. It is therefore mainly a visualization tool rather than a reusable feature transformation for a predictive pipeline.

14.6 UMAP

Uniform Manifold Approximation and Projection (UMAP) is a nonlinear dimension-reduction method designed to preserve local neighborhood structure.

At a high level, UMAP:

  1. finds nearest neighbors in the original space;
  2. converts local distances into weighted graph connections;
  3. constructs a corresponding graph in the low-dimensional space;
  4. optimizes the low-dimensional coordinates so the two graphs agree.

The method adapts connection strengths to local density rather than using one global distance bandwidth for all observations.

14.6.1 UMAP in Python

The standard Python implementation is provided by umap-learn.

uv add umap-learn
import umap
from sklearn.datasets import load_digits
from sklearn.preprocessing import StandardScaler

digits = load_digits()
X_digits = StandardScaler().fit_transform(digits.data)
y_digits = digits.target

reducer = umap.UMAP(
    n_neighbors=15,
    min_dist=0.1,
    n_components=2,
    metric="euclidean",
    random_state=1,
)

X_umap = reducer.fit_transform(X_digits)

plt.scatter(
    X_umap[:, 0],
    X_umap[:, 1],
    c=y_digits,
    cmap="tab10",
    s=10,
)
plt.xlabel("UMAP1")
plt.ylabel("UMAP2")
plt.title("Digits UMAP");

The labels are used for coloring only and are not supplied to the unsupervised embedding.

14.6.2 Main Tuning Parameters

Parameter Role Typical effect
n_neighbors size of the local neighborhood graph smaller emphasizes local detail; larger uses broader structure
min_dist minimum spacing encouraged in the embedding smaller permits tighter groups
n_components output dimension usually 2 or 3 for visualization
metric original-space dissimilarity changes which observations are neighbors

The two most visible parameters are n_neighbors and min_dist.

  • Small n_neighbors may separate fine local patterns but can fragment a continuous population.
  • Large n_neighbors smooths over local detail and gives more weight to broader structure.
  • Small min_dist produces compact visual groups.
  • Large min_dist produces a more even spread.

14.6.3 Sensitivity Analysis

A UMAP plot should be checked under several reasonable settings.

settings = [
    (5, 0.05),
    (15, 0.10),
    (50, 0.10),
    (50, 0.50),
]

fig, axs = plt.subplots(2, 2, figsize=(10, 8))

for ax, (n_neighbors, min_dist) in zip(axs.ravel(), settings):
    reducer = umap.UMAP(
        n_neighbors=n_neighbors,
        min_dist=min_dist,
        random_state=1,
    )
    embedding = reducer.fit_transform(X_digits)
    ax.scatter(
        embedding[:, 0],
        embedding[:, 1],
        c=y_digits,
        cmap="tab10",
        s=6,
    )
    ax.set_title(
        f"n_neighbors={n_neighbors}, min_dist={min_dist}"
    )

plt.tight_layout();

Structures that persist across preprocessing choices, random seeds, and reasonable tuning settings are more credible than features visible in one plot only.

14.7 What an Embedding Plot Does Not Show

Low-dimensional embeddings are useful but easy to overinterpret.

CautionApparent clusters are not proof of clusters

t-SNE, UMAP, Isomap, and spectral embeddings distort some distances to preserve selected geometric relationships. A visible gap may be affected by graph construction, optimization, initialization, or tuning. If clustering is the goal, fit and evaluate a clustering procedure rather than treating separated colors or islands as self-validating evidence.

In particular:

  • axis directions usually have no direct feature interpretation;
  • distances between far-apart groups may be unreliable;
  • group sizes and densities in the plot need not match original-space densities;
  • different runs may rotate, reflect, or rearrange the embedding;
  • an embedding fitted to all observations can leak test-set information in a predictive workflow.

For supervised modeling, fit preprocessing and embedding steps using the training data only whenever the method supports transforming new observations.

14.8 Comparing the Methods

Method Representation Main strength Main limitation
PCA linear scores interpretable loadings and optimal low-rank reconstruction only linear structure
Spectral embedding Laplacian eigenvectors exposes graph connectivity and non-convex groups graph construction and eigen-decomposition can be costly
Isomap MDS of graph geodesic distances preserves global geometry along a curved manifold sensitive to graph shortcuts and disconnected regions
SOM prototypes on a regular grid discrete topology-preserving exploratory map training and grid choices affect the result
t-SNE neighborhood probability matching strong local visualization of complex groups weak global interpretation and no standard out-of-sample transform
UMAP optimized neighborhood graph flexible nonlinear visualization and transform support tuning-sensitive; global geometry is not guaranteed

PCA is usually the first method to try because it is fast, deterministic up to signs, and interpretable. Graph methods are appropriate when local connectivity is central or linear projections fail to reveal useful structure.

14.9 Practical Workflow

  1. Choose and preprocess features based on the scientific question.
  2. Start with PCA as a transparent baseline.
  3. Use Isomap when geodesic distance along a manifold is meaningful.
  4. Use t-SNE or UMAP when local neighborhood visualization is the primary goal.
  5. Build graph embeddings only after deciding what distance and neighborhood should mean.
  6. Repeat the analysis across plausible tuning choices and random seeds.
  7. Evaluate clusters in the original feature space and check stability.
  8. Treat the embedding as a representation, not as ground truth.

14.10 Summary

Spectral methods use Laplacian eigenvectors to turn graph connectivity into features, after which ordinary clustering can be applied. Isomap preserves shortest-path distances along a neighborhood graph. SOM organizes prototype vectors on a grid. t-SNE matches local neighborhood probabilities, while UMAP optimizes a low-dimensional graph. These methods can reveal nonlinear structure, but their output inherits the preprocessing, neighborhood, tuning, and optimization choices used to construct the representation.
