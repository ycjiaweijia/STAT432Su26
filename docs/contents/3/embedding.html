14  Embedding for Visualization

The previous chapter introduced PCA as linear dimension reduction. An embedding is the more general idea of representing high-dimensional observations with a smaller number of coordinates:

\[ x_i\in\mathbb R^p \longrightarrow z_i\in\mathbb R^m, \qquad m\ll p. \]

PCA from Chapter 13 is therefore a linear embedding. It preserves as much variance as possible in a linear subspace and provides loadings that connect the new coordinates to the original features.

This chapter focuses on nonlinear embeddings whose main purpose is visualization, usually with \(m=2\). We study two widely used methods:

  • t-distributed stochastic neighbor embedding (t-SNE);
  • uniform manifold approximation and projection (UMAP).

Both methods prioritize local neighborhoods: observations that are similar in the original feature space should usually appear near one another in the plot. Unlike PCA, however, their axes generally do not have direct feature interpretations, and the plot does not preserve every original distance.

NoteVisualization is the main goal here

UMAP can also produce more than two coordinates and can transform new observations after fitting. Nevertheless, we use both t-SNE and UMAP here primarily as exploratory visualization methods.

14.1 Before Constructing an Embedding

An embedding is built from the features and their distances or neighborhoods. The following choices therefore affect the result before the algorithm begins:

  • which features are included;
  • whether features are centered, scaled, or transformed;
  • how missing values are handled;
  • which distance metric defines similarity;
  • whether a preliminary PCA step removes redundant or noisy directions.

For high-dimensional data, a common workflow is

\[ X \longrightarrow \text{scaled features} \longrightarrow \text{optional PCA} \longrightarrow \text{two-dimensional embedding}. \]

PCA preprocessing is especially common before t-SNE. It reduces computation and can remove directions dominated by noise, but it should retain enough components to preserve the structure of interest.

14.2 t-SNE

t-SNE is a nonlinear embedding method designed primarily for visualization. It converts high-dimensional distances into neighborhood probabilities and then seeks low-dimensional coordinates with similar neighborhood probabilities.

Its emphasis is local: close neighbors are represented carefully, while distances between widely separated groups receive much less protection.

14.2.1 Neighborhood Probabilities

For each observation \(i\), t-SNE defines the probability that \(i\) would select observation \(j\) as a neighbor:

\[ p_{j\mid i} = \frac{ \exp\qty(-\norm{x_i-x_j}^2/(2\sigma_i^2)) }{ \sum_{k\ne i} \exp\qty(-\norm{x_i-x_k}^2/(2\sigma_i^2)) }, \qquad j\ne i. \]

The bandwidth \(\sigma_i\) adapts to the local density. These conditional probabilities are symmetrized to obtain high-dimensional similarities \(p_{ij}\).

For low-dimensional coordinates \(z_i\), t-SNE uses a heavy-tailed Student-\(t\) similarity:

\[ q_{ij} = \frac{(1+\norm{z_i-z_j}^2)^{-1}} {\sum_{k\ne \ell}(1+\norm{z_k-z_\ell}^2)^{-1}}. \]

The heavy tail helps separate observations that cannot all fit into a small two-dimensional neighborhood.

t-SNE chooses the coordinates by minimizing

\[ \operatorname{KL}(P\Vert Q) = \sum_{i\ne j} p_{ij}\log\qty(\frac{p_{ij}}{q_{ij}}). \]

The asymmetric objective strongly penalizes placing true neighbors far apart. It penalizes false neighbors less strongly, which is one reason local structure is more trustworthy than global spacing in a t-SNE plot.

14.2.2 Digits Example

The handwritten digits dataset contains 64 pixel features. We standardize the features, retain 30 PCA components, and then construct a two-dimensional t-SNE embedding.

import matplotlib.pyplot as plt

from sklearn.datasets import load_digits
from sklearn.decomposition import PCA
from sklearn.manifold import TSNE
from sklearn.preprocessing import StandardScaler

digits = load_digits()
X_digits = StandardScaler().fit_transform(digits.data)
y_digits = digits.target

X_digits_pca = PCA(
    n_components=30,
    random_state=1,
).fit_transform(X_digits)

tsne = TSNE(
    n_components=2,
    perplexity=30,
    init="pca",
    learning_rate="auto",
    max_iter=1000,
    random_state=1,
)
X_tsne = tsne.fit_transform(X_digits_pca)

fig, ax = plt.subplots(figsize=(8, 6))
scatter = ax.scatter(
    X_tsne[:, 0],
    X_tsne[:, 1],
    c=y_digits,
    cmap="tab10",
    s=10,
    alpha=0.75,
)
ax.set_xlabel("t-SNE1")
ax.set_ylabel("t-SNE2")
ax.set_title("Digits t-SNE")
ax.legend(
    *scatter.legend_elements(),
    title="digit",
    ncol=2,
);

The class labels are used only for coloring and interpretation. They are not used to fit PCA or t-SNE.

14.2.3 Perplexity and Sensitivity

The main tuning parameter is perplexity. It is related to the effective number of neighbors considered around each observation.

  • Smaller perplexity emphasizes very local structure and may fragment the embedding.
  • Larger perplexity uses broader neighborhoods but may smooth over local detail.

The result also depends on initialization, learning rate, iteration count, and random seed. A visual pattern is more credible when it persists across several reasonable settings.

CautionInterpreting t-SNE

Distances between separated groups, group sizes, and empty space in a t-SNE plot do not generally have direct quantitative meaning. Visually distinct islands are not by themselves evidence that discrete clusters exist.

Standard sklearn t-SNE also has no .transform() method for new observations. It is mainly an exploratory visualization rather than a reusable feature transformation for a predictive pipeline.

14.3 UMAP

UMAP is another nonlinear dimension-reduction method that emphasizes local neighborhood structure. At a high level, it:

  1. finds nearest neighbors in the original feature space;
  2. converts local distances into weighted graph connections;
  3. constructs a corresponding graph in the low-dimensional space;
  4. optimizes coordinates so the two graphs agree as closely as possible.

UMAP adapts connection strengths to local density rather than applying one global distance bandwidth to every observation.

14.3.1 UMAP in Python

The standard Python implementation is provided by umap-learn.

uv add umap-learn
import umap

reducer = umap.UMAP(
    n_neighbors=15,
    min_dist=0.1,
    n_components=2,
    metric="euclidean",
    random_state=1,
)

X_umap = reducer.fit_transform(X_digits)

fig, ax = plt.subplots(figsize=(8, 6))
scatter = ax.scatter(
    X_umap[:, 0],
    X_umap[:, 1],
    c=y_digits,
    cmap="tab10",
    s=10,
    alpha=0.75,
)
ax.set_xlabel("UMAP1")
ax.set_ylabel("UMAP2")
ax.set_title("Digits UMAP")
ax.legend(
    *scatter.legend_elements(),
    title="digit",
    ncol=2,
);

Again, the digit labels are used only to interpret the resulting plot.

14.3.2 Main Tuning Parameters

Parameter Role Typical effect
n_neighbors size of the local neighborhood smaller emphasizes local detail; larger uses broader structure
min_dist minimum spacing encouraged in the embedding smaller permits tighter visual groups
n_components output dimension usually 2 for visualization
metric original-space dissimilarity changes which observations are neighbors

n_neighbors controls the scale of structure emphasized by UMAP. min_dist mainly controls how tightly observations can be packed in the display. A compact island produced by a small min_dist should not automatically be interpreted as a dense cluster in the original space.

14.3.3 Sensitivity Analysis

The same data can produce visibly different plots under different parameters. A useful analysis compares several plausible settings.

settings = [
    (5, 0.05),
    (15, 0.10),
    (50, 0.10),
    (50, 0.50),
]

fig, axs = plt.subplots(2, 2, figsize=(10, 8))

for ax, (n_neighbors, min_dist) in zip(
    axs.ravel(),
    settings,
):
    reducer = umap.UMAP(
        n_neighbors=n_neighbors,
        min_dist=min_dist,
        random_state=1,
    )
    embedding = reducer.fit_transform(X_digits)
    ax.scatter(
        embedding[:, 0],
        embedding[:, 1],
        c=y_digits,
        cmap="tab10",
        s=6,
    )
    ax.set_title(
        f"n_neighbors={n_neighbors}, "
        f"min_dist={min_dist}"
    )

plt.tight_layout();

Structures that persist across preprocessing choices, random seeds, and reasonable tuning settings are more credible than features visible in one plot only.

14.4 Comparing PCA, t-SNE, and UMAP

PCA provides the linear baseline; t-SNE and UMAP are nonlinear alternatives for local visualization.

Property PCA t-SNE UMAP
Mapping linear nonlinear nonlinear
Main goal here variance-preserving representation local visualization local visualization
Axis interpretation loadings connect axes to features axes have no direct meaning axes have no direct meaning
Global distances partially preserved by linear projection generally unreliable not guaranteed
Main tuning choices number of components, scaling perplexity, optimization settings neighbors, minimum distance, metric
New observations .transform() available no standard sklearn transform transform supported

PCA should usually be the first visualization because it is fast, transparent, and comparatively stable. t-SNE or UMAP can then reveal local patterns that a two-dimensional linear projection misses.

The nonlinear plots should not be judged by which one looks most separated. Instead, ask whether the visible neighborhoods are stable and whether they correspond to meaningful differences in the original variables.

14.5 What an Embedding Plot Does Not Show

CautionApparent clusters are not proof of clusters

t-SNE and UMAP intentionally distort some distances to preserve selected neighborhood relationships. A visible gap may be caused or enlarged by preprocessing, tuning, initialization, or optimization. If clustering is the goal, fit and evaluate a clustering method rather than using islands in an embedding as the cluster definition.

In particular:

  • axis directions usually have no direct feature interpretation;
  • distances between far-apart groups may be unreliable;
  • displayed group sizes and densities need not match original-space densities;
  • different runs may rotate, reflect, or rearrange the embedding;
  • fitting an embedding to all observations can leak test information in a predictive workflow.

Embedding coordinates should guide exploration. Scientific interpretation must return to the original features and observations.

14.6 Practical Workflow

  1. Select features that match the scientific question.
  2. Handle missing values and choose scaling deliberately.
  3. Start with a two-dimensional PCA plot.
  4. Use t-SNE or UMAP when nonlinear local structure is of interest.
  5. Compare plausible tuning values and random seeds.
  6. Investigate visible groups using the original variables.
  7. Apply a clustering method separately if formal grouping is needed.

14.7 Summary

Embedding is a form of dimension reduction. In this chapter, its main purpose is to visualize high-dimensional observations in two dimensions. PCA supplies a linear baseline, while t-SNE and UMAP emphasize local neighborhoods through nonlinear mappings. Their plots are useful exploratory representations, but axis values, global distances, apparent densities, and visible gaps must be interpreted cautiously. As emphasized in Chapter 12, a visualization may suggest structure, but it does not by itself define or validate a clustering.
