Statistical Learning Basics

Introduction

What Is Statistical Learning?

Statistical learning studies how to use data to understand relationships and make predictions.

A common abstract model is

\[ Y = f(X) + \varepsilon, \]

where:

  • \(X\) represents predictors;
  • \(Y\) represents the response;
  • \(f\) is the underlying relationship;
  • \(\varepsilon\) represents random noise or unexplained variation.

The main objective of statistical learning is to estimate the unknown function \(f\) using observed data.

Core Perspective

Modern statistical learning is fundamentally about:

learning patterns that generalize well to unseen data.

This perspective motivates many major topics:

  • linear models,
  • regularization,
  • trees,
  • boosting,
  • neural networks,
  • ensemble methods,
  • cross-validation.

Classical Statistics vs Modern Machine Learning

Historically:

Classical Statistics Modern Machine Learning
inference prediction
interpretable models predictive performance
smaller datasets large datasets
stronger assumptions weaker assumptions

Modern statistical learning often combines ideas from both areas.

Types of Learning

Supervised Learning

In supervised learning, we observe both predictors \(X\) and response \(Y\).

The goal is to predict or explain the response.

Examples:

  • house price prediction,
  • spam detection,
  • medical diagnosis.

Regression and Classification

Within supervised learning, two major tasks are:

  • regression, where the response is quantitative;
  • classification, where the response is categorical.

Examples:

  • predicting salary is a regression problem;
  • predicting whether a tumor is benign or malignant is a classification problem.

Unsupervised Learning

In unsupervised learning, we observe predictors \(X\) but no response \(Y\).

The goal is to discover hidden structure in the data.

Examples:

  • clustering,
  • dimensionality reduction,
  • anomaly detection.

Reinforcement Learning

In reinforcement learning, an agent interacts with an environment and learns through rewards and penalties.

Examples:

  • robotics,
  • game playing,
  • recommendation systems.

Different Types of Data

Machine learning methods are strongly connected to data structure, and different data types often require different modeling strategies.

This course mainly focuses on tabular data, which is the classical setting in statistics and applied machine learning.

Tabular Data

Tabular data is typically represented as

\[ X \in \mathbb{R}^{n \times p}, \]

where:

  • \(n\) is the number of observations;
  • \(p\) is the number of predictors.

Example:

Age Income Balance Student Default
23 50000 1200 Yes No
45 90000 3000 No Yes

In tabular data:

  • rows represent observations;
  • columns represent variables or features.

Examples:

  • finance,
  • healthcare,
  • insurance,
  • marketing,
  • scientific experiments.
NoteMain Idea

The key feature of tabular data is not merely the matrix representation. More importantly, each column corresponds to a variable with its own semantic meaning, such as age, income, blood pressure, or transaction count.

NoteOther types: Image Data

Image data contains spatial structure, meaning nearby pixels are highly related.

Modern image models frequently use:

  • convolutional neural networks,
  • vision transformers.

A central goal is to extract meaningful visual patterns such as edges, textures, shapes, and objects.

NoteOther types: Text Data

Text data contains sequential and contextual structure.

Modern NLP is largely based on:

  • transformers,
  • large language models.
NoteOther types: Time Series Data

Time series data is ordered over time.

Examples:

  • stock prices,
  • weather data,
  • sensor measurements.

Important ideas include:

  • trend,
  • seasonality,
  • temporal dependence.
NoteOther types: Graph Data

Graph data represents relationships between objects.

Examples:

  • social networks,
  • citation networks,
  • molecular structures.

Modern graph learning often uses graph neural networks.

Main Questions in Statistical Learning

At a high level, statistical learning studies one central question:

How can we learn useful patterns from data?

This leads to several different kinds of questions.

Prediction

Prediction asks:

What will happen for a new observation?

Prediction is often the primary goal in modern machine learning.

Mathematically, prediction is often viewed as estimating

\[ \hat f(x) \approx \mathbb{E}[Y \mid X=x]. \]

Examples:

  • Will a customer default?
  • What will tomorrow’s demand be?
  • Will a patient develop a disease?

In practice, prediction mainly focuses on predictive performance.

Inference and Understanding

Inference asks:

Which variables matter, and how are they related to the response?

Examples:

  • Does smoking increase disease risk?
  • Which features drive customer churn?
  • Which predictors are statistically significant?

Common tools include:

  • standard errors,
  • confidence intervals,
  • hypothesis testing.

Inference usually relies more heavily on model assumptions and diagnostics.

Causality

Causality asks:

What happens if we intervene?

A causal question is often written as

\[ \mathbb{E}[Y \mid do(X=x)]. \]

Examples include:

  • randomized experiments,
  • instrumental variables,
  • difference-in-differences.
NoteImportant Distinctions
Task Main Question
Prediction What will happen?
Inference Is there a relationship?
Causality What happens if we intervene?

Important points:

  1. Good training performance does not imply good generalization.
  2. Good prediction does not imply valid inference.
  3. Association does not imply causation.

Generalization and Model Complexity

Training Error and Test Error

Classical regression focuses heavily on checking model assumptions, such as:

  • independence of errors,
  • constant variance,
  • approximate normality.

These assumptions are especially important for formal inference, including confidence intervals and hypothesis testing.

In statistical learning, however, the primary goal is often predictive performance rather than formal inference. As a result, diagnostic tools still remain useful, but they usually play a secondary role. Their main purpose is often to detect serious issues such as:

  • strong nonlinearity,
  • influential observations,
  • data quality problems,
  • severe model misspecification.

The central question becomes:

How well does the model predict new observations?

Definition 1 (Training Error) The training error measures how well a model fits the training data.

Definition 2 (Test Error) The test error measures prediction error on new observations not used to fit the model.

For example, suppose we evaluate a regression model using mean squared error (MSE).

The training MSE measures fit on the observed training sample, while the test MSE measures prediction performance on new data drawn from the same population.

A model may achieve extremely small training error while still performing poorly on unseen data. This happens because the model begins fitting random noise rather than the underlying signal.

Definition 3 (Overfitting) Overfitting occurs when a model fits the training data very closely but fails to generalize well to new data. In this case, the model captures random noise or idiosyncrasies in the training sample rather than the underlying relationship.

The goal of statistical learning is therefore:

to build models with small test error, not merely small training error.

Model selection methods attempt to balance model complexity and prediction accuracy in order to avoid overfitting.

Bias–Variance Tradeoff

A central idea behind generalization is the bias–variance tradeoff.

Suppose

\[ Y=f(X)+\varepsilon, \qquad \Var(\varepsilon)=\sigma^2. \]

For a fitted estimator \(\hat f\), the test mean squared error at \(x_0\) satisfies

\[ \mathbb{E} \left[ (Y_0-\hat f(x_0))^2 \right] = \operatorname{Bias}^2(\hat f(x_0)) + \operatorname{Var}(\hat f(x_0)) + \sigma^2. \]

The three terms represent:

  • bias: systematic modeling error;
  • variance: sensitivity to the training sample;
  • irreducible error: noise that cannot be removed.

Roughly speaking:

  • simple models:
    • higher bias,
    • lower variance;
  • flexible models:
    • lower bias,
    • higher variance.

As model flexibility increases:

  • training error usually decreases;
  • test error often first decreases and then increases.

Model selection aims to balance these two effects in order to achieve good generalization performance.

NoteMain Point

Many modern methods can be viewed as ways to control the bias–variance tradeoff. Regularization, cross-validation, ensemble methods, trees, boosting, and neural networks can all be understood from this perspective.

NoteInformation Criteria and Estimated Test Error

Classical regression often estimates expected test error indirectly using only the training data.

Some commonly used criteria are:

  • AIC (Akaike Information Criterion),
  • BIC (Bayesian Information Criterion),
  • Mallows’ \(C_p\).

These criteria reward good fit while penalizing excessive model complexity.

Although they are useful for model comparison, they still rely on approximations derived from the training sample.

A Typical Statistical Learning Workflow

A practical workflow often looks like this:

  1. define the problem;
  2. preprocess and explore the data;
  3. choose candidate models;
  4. estimate test error using validation or cross-validation;
  5. compare models;
  6. interpret and communicate results.

The overall goal is:

to build models that generalize well while remaining scientifically useful.
