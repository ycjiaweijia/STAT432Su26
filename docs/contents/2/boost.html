Boosting is another ensemble method. Like bagging and random forests, it combines many trees into one model. The difference is how the trees are built.

Bagging and random forests build trees independently and then average them.

Boosting builds trees sequentially. Each new tree is trained to improve the current ensemble.

The central idea is:

Build many weak learners one at a time, and let each new learner focus on what the current model still gets wrong.

This chapter first discusses AdaBoost. AdaBoost is historically important and is the cleanest way to see the boosting idea. We then discuss the margin effect of AdaBoost and how to tune its hyperparameters. Finally, we discuss gradient boosting and use XGBoost as the main implementation example.

13.1 AdaBoost

AdaBoost (Adaptive Boosting) was introduced by Yoav Freund and Robert E. Schapire in 1995 [1] as one of the first highly successful boosting algorithms. Their original work showed that many weak learners, each performing only slightly better than random guessing, could be combined into a highly accurate classifier. AdaBoost became a foundational method in statistical learning, and it strongly influenced the later development of modern boosting methods such as Gradient Boosting and XGBoost.

The original AdaBoost algorithm was proposed as a classification method. Regression extensions were developed later after the success of AdaBoost classifiers. In this course, we mainly study AdaBoost classification because it introduces the core ideas of boosting in a simple and historically important setting.

For regression problems, we will move on to gradient boosting methods, which have become the dominant boosting framework in modern machine learning.

To keep the notation simple, assume the response is binary:

\[ y_i\in\{-1,+1\}. \]

AdaBoost constructs a classifier of the form

\[ F_M(x) = \sum_{m=1}^M \alpha_m G_m(x), \]

where:

  • \(G_m(x)\) is the \(m\)-th weak classifier,
  • \(\alpha_m\) is the weight assigned to that classifier,
  • \(M\) is the number of boosting rounds.

The final prediction is

\[ \hat G(x) = \operatorname{sign}\{F_M(x)\}. \]

Thus AdaBoost is a weighted voting method. Classifiers with larger \(\alpha_m\) have more influence in the final vote.

13.1.1 Weak Learners

AdaBoost is built from weak learners.

A weak learner is a classifier that is only slightly better than random guessing. In tree-based AdaBoost, the most common weak learner is a decision stump, which is a tree with only one split.

In sklearn, a decision stump is created by

from sklearn.tree import DecisionTreeClassifier

DecisionTreeClassifier(max_depth=1)

A decision stump is extremely simple and usually underfits when used alone. One of the most surprising and important ideas behind AdaBoost is that by combining many such weak learners sequentially, the resulting ensemble can become a highly accurate and powerful model.

13.1.2 Weights of observations

In AdaBoost, there are two different types of weights.

  • Estimator weights (\(\alpha_m\)) determine how much influence each weak learner has in the final ensemble.
  • Observation weights (\(w_i^{(m)}\)) determine which training observations receive more attention when fitting the next learner.

During training, AdaBoost repeatedly updates the weights of the training observations. Observations that are difficult to classify receive larger weights, so future learners focus more on them.

To understand this process, we need to discuss how a decision tree is trained on a weighted dataset.

The main idea is very simple. In an ordinary dataset, quantities such as class frequencies and node sample counts are computed using the number of observations. For a weighted dataset, these counts are replaced by weighted counts, that is, by the sum of the observation weights.

For example, suppose a node contains observations with weights \(w_1,w_2,\dots,w_n\). Then the effective sample size of the node becomes \(\sum_{i=1}^n w_i\). Similarly, class proportions are computed using weighted proportions rather than ordinary proportions.

Therefore, training a decision tree on weighted data is conceptually very similar to ordinary tree training. We simply replace ordinary counts by weighted counts throughout the splitting calculations.

Example 13.1 Consider the following data:

x0 x1 y Weight
1.0 2.1 + 0.5
1.0 1.1 + 0.125
1.3 1.0 - 0.125
1.0 1.0 - 0.125
2.0 1.0 + 0.125

The weighted Gini impurity is

\[ \text{WeightedGini}=1-(0.5+0.125+0.125)^2-(0.125+0.125)^2=0.375. \]

13.1.3 The AdaBoost Algorithm

Suppose we have training data

\[ (x_1,y_1),\ldots,(x_n,y_n), \quad y_i\in\{-1,+1\}. \]

Initialize observation weights:

\[ w_i^{(1)}=\frac1n. \]

Then AdaBoost proceeds as follows.

  1. For boosting round \(m=1,\ldots,M\), fit a weak classifier \(G_m\) using the current weights.
  2. Compute the weighted classification error by the \(m\)-th classifier: \[ \operatorname{err}_m =\frac{\text{the total weights of misclassified observations}}{\text{the total weights}}= \frac{ \sum_{\text{misclassified}} w_i^{(m)} }{ \sum_{\text{all}} w_i^{(m)} }. \]
  3. Assign a weight to the weak classifier: \[ \alpha_m = \eta\cdot\log\qty(\frac{1-\operatorname{err}_m}{\operatorname{err}_m}). \]
  4. Update observation weights and then normalize the weights so they sum to one: \[ w^{(m+1)}_{i}\xleftarrow{\text{normalize}} \hat w_i^{(m+1)}\leftarrow\begin{cases}w^{(m)}_i\exp(-\alpha_m)&\text{if the $m$th data is correctly classified,}\\ w_i^{(m)}\exp(\alpha_m)&\text{if the $m$th data is misclassified.}\end{cases} \] that \[ w^{(m+1)}_{i}=\frac{\hat w_i^{(m+1)}}{\sum_j \hat w_j^{(m+1)}}. \] It is easy to see from the updating rule that AdaBoost puts more weight on observations that were misclassified.
  5. Repeat the above process until the stop conditions are met.

The final model is then \[ F_M(x) = \sum_{m=1}^M \alpha_m G_m(x), \] and the final prediction is \[ \hat G(x) = \operatorname{sign}\qty{F_M(x)}. \]

NoteLearning Rate

The \(\eta>0\) in Step 3 is the learning rate. Some textbooks include an additional factor \(\frac12\) in front of \(\eta\). This only changes the scale of the classifier weights and can therefore be absorbed into the learning rate. So we will not use the factor.

The learning rate controls how much each weak learner contributes to the final ensemble. A larger learning rate makes the model change more aggressively at each iteration, while a smaller learning rate produces more gradual updates.

In practice, smaller learning rates are often combined with a larger number of estimators.

NoteMargin

\(yF(x)\) is called the margin of the model \(F\) on the observation \((x,y)\). Since AdaBoost uses \(\operatorname{sign}\qty{F(x)}\) as the final prediction rule, the margin can be interpreted as a confidence score for the prediction.

  • If the margin is positive, the prediction is correct.
  • If the margin is negative, the prediction is incorrect.
  • A larger positive margin indicates a more confident prediction.
  • A margin close to zero indicates uncertainty.

Notice that the observation weight updating formula can be rewritten as \[ w_i^{(m+1)} = w_i^{(m)} \exp\qty(-\alpha_m y_i G_m(x_i)), \] where \(y_i G_m(x_i)\) is exactly the margin of the weak learner \(G_m\) on observation \((x_i,y_i)\).

Therefore, AdaBoost increases the weights of observations with small or negative margins and decreases the weights of observations with large positive margins. In this sense, AdaBoost can be viewed as an algorithm that attempts to improve the margin distribution by pushing margins toward larger positive values.

Margin theory is one of the central ideas in boosting and helps explain why boosting methods often continue to improve test performance even after the training error has already reached zero. We will discuss this topic in more detail later.

NoteWhy the Learner Weight Makes Sense

The classifier weight is

\[ \alpha_m = \eta\cdot\log\left( \frac{1-\operatorname{err}_m}{\operatorname{err}_m} \right). \]

  • If \(\operatorname{err}_m\) is small, then the classifier is useful and \(\alpha_m\) is large.
  • If \(\operatorname{err}_m\) is close to \(0.5\), then the classifier is close to random guessing and \(\alpha_m\) is close to zero.
  • If \(\operatorname{err}_m>0.5\), then the classifier is worse than random guessing. In practice, this means the weak learner is not doing its job.

13.1.4 Why Does AdaBoost Work So Well?

One of the most surprising aspects of AdaBoost is that it often works extremely well even when the base learners are very weak.

Several intuitive explanations are commonly used:

  • each weak learner makes a small correction to the current model
  • difficult observations receive more attention in later iterations
  • many simple rules can combine into a highly flexible decision boundary
  • weak learners may help reduce overfitting by forcing gradual improvements

From a practical viewpoint, AdaBoost can be viewed as repeatedly combining many simple models into a stronger ensemble.

However, understanding why AdaBoost works so well mathematically became one of the major research topics in statistical learning during the late 1990s and early 2000s. Many theoretical studies showed that AdaBoost is closely connected to several important topics, including additive modeling, exponential loss minimization, margin theory, and statistical learning theory.

One particularly influential result showed that AdaBoost can be interpreted as a stagewise additive optimization procedure. Important theoretical works include [2], [3], [4], and [5]. These studies greatly influenced the later development of modern boosting methods such as Gradient Boosting and XGBoost.

13.2 AdaBoost in Python

The basic APIs are as usual. Here we use make_moons to create a test dataset to demo the model.

from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split

X, y = make_moons(n_samples=1200, noise=0.08, random_state=2)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=1)

We use AdaBoostClassifier from sklearn.ensemble to implement AdaBoost. All the regular APIs are the same.

from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import AdaBoostClassifier

ada = AdaBoostClassifier(
    estimator=DecisionTreeClassifier(max_depth=1),
    n_estimators=800,
    learning_rate=0.1,
    random_state=1,
)

ada.fit(X_train, y_train)
ada.score(X_test, y_test)

13.2.1 SAMME and SAMME.R

The original AdaBoost algorithm was designed for binary classification. Later extensions such as SAMME and SAMME.R generalized AdaBoost to multiclass classification problems. In sklearn, multiclass classification for AdaBoostClassifier is implemented using the SAMME algorithm by default.

However, these variants are less important in modern statistical learning practice and will not be studied in detail in this course. One reason is that these extensions substantially increase the algorithmic complexity while introducing relatively limited new conceptual ideas beyond the original AdaBoost framework. In particular, SAMME.R relies heavily on predicted class probabilities, making the method more sensitive to the quality of probability estimation and numerical stability.

More importantly, many of the key ideas behind SAMME.R already overlap with the additive optimization viewpoint used in modern gradient boosting methods. As a result, modern frameworks such as Gradient Boosting and XGBoost provide a more general, flexible, and unified approach for both regression and classification problems.

Consequently, we will focus primarily on the original AdaBoost classifier as an accessible introduction to the core ideas of boosting before moving directly to Gradient Boosting. Reflecting a similar shift in modern machine learning practice, sklearn has also deprecated SAMME.R in recent versions due to its reliance on probability estimation and its conceptual overlap with more general gradient boosting frameworks.

13.2.2 The Margin Effect of AdaBoost

AdaBoost is often explained as an algorithm that reduces training error. However, its behavior is more subtle than that.

For a binary classifier with labels \(y_i\in\{-1,+1\}\), define the margin of observation \(i\) as

\[ \operatorname{margin}_i = y_iF_M(x_i). \]

The sign of the margin determines whether the observation is classified correctly:

  • if \(\operatorname{margin}_i>0\), the observation is correctly classified;
  • if \(\operatorname{margin}_i<0\), the observation is misclassified.

The magnitude of the margin measures confidence. A large positive margin means the ensemble strongly supports the correct class.

13.2.3 Why Margins Matter

AdaBoost often continues to improve test performance even after the training error has reached zero. This can seem surprising. If the training error is already zero, what is left to improve?

The answer is margins.

After all training observations are classified correctly, AdaBoost may still increase the margins. Larger margins mean the classifier is more confident and more stable. This can improve generalization.

NoteMargin view

Training error only asks whether the margin is positive.

The margin view also asks how positive it is.

This is one reason AdaBoost can work well in practice. It does not only try to classify points correctly. It also tends to push correctly classified points farther away from the decision boundary.

13.4 Gradient Boosting: Optimization View

The core idea of boosting is to sequentially train models in order to correct the errors made by earlier models. A natural idea is therefore:

  1. fit a model
  2. compute the residuals
  3. fit a new model to the residuals
  4. repeat

This idea leads directly to Gradient Boosting.

In this section we mainly consider regression problems first.

13.4.1 Additive model

Gradient Boosting builds an additive model of the form

\[ F_M(x) = \sum_{m=1}^M \beta_m h_m(x) \]

where

  • \(h_m(x)\) is usually a small regression tree
  • \(\beta_m\) is a coefficient
  • the model is built sequentially

Unlike bagging, where trees are trained independently, boosting trains each new tree based on the current errors of the model.

13.4.2 Optimization viewpoint

Suppose we want to minimize the empirical loss

\[ L(F)=\sum_{i=1}^n l(y_i,F(x_i)), \]

where \(\qty{(x_i,y_i)}\) is the training dataset.

Assume the current model is \(F_m(x)\). After adding a new tree \(f_m(x)\), the next model becomes

\[ F_{m+1}(x)=F_m(x)+f_m(x). \]

The new tree \(f_m(x)\) is chosen to reduce the loss function as much as possible.

13.4.3 Gradient Boosting and pseudo-residuals

To understand how to choose \(f_m(x)\), consider the first-order Taylor expansion \[ l(y_i,F_m(x_i)+f_m(x_i))\approx l(y_i,F_m(x_i))+g_i f_m(x_i), \] where \[ g_i=\left.\frac{\partial l(y_i,F(x_i))}{\partial F(x_i)}\right|_{F=F_m}. \]

This is a linear approximation of the loss function around the current model.

To reduce the loss most rapidly, we move in the negative gradient direction. Therefore we define the pseudo-residual

\[ r_i=-g_i=-\left. \frac{\partial l(y_i,F(x_i))} {\partial F(x_i)} \right|_{F=F_m}. \]

The pseudo-residual plays the role of the “error signal” that the next tree should fit.

Therefore, Gradient Boosting trains a regression tree using \(r_i\) as the target values (with more details discussed in the next section).

13.4.4 Regression tree fitting

In order to find the best model \(F(x)\), we would like to minimize the empirical loss function

\[ L(F) = \sum_{i=1}^n l(y_i,F(x_i)), \]

where \(\{(x_i,y_i)\}\) is the training dataset.

One of the most common choices is the squared-error loss

\[ L(F) = \sum_{i=1}^n (y_i-F(x_i))^2. \]

Assume the current model is \(F_m(x)\). After adding a new tree \(f_m(x)\), the next model becomes

\[ F_{m+1}(x) = F_m(x)+f_m(x). \]

The new tree \(f_m(x)\) is chosen to reduce the loss function as much as possible.

Now consider the first-order Taylor expansion of the loss function:

\[ l(y_i,F_m(x_i)+f_m(x_i)) \approx l(y_i,F_m(x_i)) + g_i f_m(x_i), \]

where

\[ g_i = \left. \frac{\partial l(y_i,F(x_i))} {\partial F(x_i)} \right|_{F=F_m}. \]

This gives a linear approximation of the loss function in terms of the update \(f_m(x_i)\).

Since the first-order Taylor approximation is linear, the negative gradient gives the direction of steepest descent. Therefore we define the pseudo-residual

\[ r_i = -g_i = - \left. \frac{\partial l(y_i,F(x_i))} {\partial F(x_i)} \right|_{F=F_m}. \]

The pseudo-residual plays the role of the error signal that the next tree should fit.

Assume that the new tree splits the dataset into regions

\[ R_1,\ldots,R_s, \]

and for each region \(R_j\) a value \(s_j\) is assigned.

We would like the tree to approximate the pseudo-residuals \(r_i\). Therefore we choose the tree to minimize

\[ \sum_{j=1}^s \sum_{x_i\in R_j} (r_i-s_j)^2. \]

For a fixed region \(R_j\), the optimal value of \(s_j\) is the mean of the observations inside that region:

\[ s_j = \frac{1}{|R_j|} \sum_{x_i\in R_j} r_i. \]

Therefore, the new tree \(f_m(x)\) is simply a regression tree (trained using RSS) with target values \(r_i\).

NotePseudo-residual

\(r_i\) is called a pseudo-residual because it is technically a negative gradient rather than an ordinary residual. However, it plays the role of the residual in Gradient Boosting.

For squared-error loss

\[ l(y,F(x)) = (y-F(x))^2, \]

we have

\[ r_i = 2(y_i-F_m(x_i)), \]

which is proportional to the ordinary residual.

Therefore, under \(L^2\) loss, Gradient Boosting can literally be interpreted as fitting residuals.

13.4.5 XGBoost: initial idea

XGBoost stands for extrem gradient boost. Its math part is a modified version of GBDT. It is a very popular model in the shallow machine learning world. Other than its math, It also has many innovations in engineerings. After the success of XGBoost, more similar models like LightBoost or CatBoost came out and all are popular in the modern world.

In this lecture we only focus on the math part of XGBoost as an introduction to this topic.

The motivation is very similar to GBDT. We are considering an additive model \[ F_{m+1}(x)=F_m(x)+f_m(x). \] and want to minimize the loss function \[ l(y,F(x))=\sum l(y_i,F(x_i)). \]

Assume the current model is \(F_m(x)\). After adding a new tree \(f_m(x)\) to get \(F_{m+1}(x)=F_m(x)+f_m(x)\), we consider the 2nd order Taylor expansion of the loss function \[ l(y_i,F_{m+1}(x_i))=l(y_i,F_{m}(x_i)+f_m(x_i))\approx l(y_i,F_m(x_i))+g_if_m(x_i)+\frac12h_if_m(x_i)^2 \] where \[ g_i=\pdv{l(y_i,f_{m}(x_i))}{f_m(x_i)},\quad h_i=\left.\frac{\partial^2 l(y_i,f_m(x_i))}{\partial (f_m(x_i))^2} \right|_{F=F_{t-1}}. \] 2nd order Taylor expansion is to use a quadratic function to approximate the original function. To minimize the loss function, we don’t need to find the fastest direction based on the gradient. We could directly find the lowest point due to the quadratic function. As a function of \(f=f_m(x_i)\), the derivate of the function \(g_if+\frac12 h_if^2\) is \(g_i+h_if\), and the critical point (which is supposed to be the lowest point) is \[ w_i=-\frac{g_i}{h_i}. \] This is the best point if the loss is a perfect quadratic function. This is the result of our additive models, and we would like to use a tree model to approximate these numbers.

Now here is the tricky part. Assume that the new tree split the dataset into \(R_1,\ldots,R_s\) regions, and for each region \(R_j\) a value \(s_j\) is assigned. We would like the tree to approximate \(w_i\). Therefore we want to choose the tree to mimimize \[ \sum_{x_i\in R_j}(g_is_j+\frac12 h_is_j^2)^2. \] For each \(x_i\in R_j\), the best \(s_j\) to minimize the above formula is \[ s_j=-\frac{\sum_{x_i\in R_j} g_i}{\sum_{x_i\in R_j} h_i}. \] If we let \(\sum_{x_i\in R_j} g_i=G_j\), \(\sum_{x_i\in R_j} h_i=H_j\), we have \[ s_j=-\frac{G_j}{H_j}. \] This will create a tree. However this tree is NOT a tree trained by CART with target \(s_j\). Its prediction formula is different.

We discussed this algorithm, we still say that we train a tree model to approximate \(g_i\) and \(h_i\). However it is important that the tree is different from the regular CART trees that we kept talking about.

13.4.6 XGBoost: regularization

The residuals are

\[ r_i = y_i-F_m(x_i). \]

A natural idea is:

  1. compute residuals
  2. fit a new tree to residuals
  3. add this tree to the model

Thus we update the model by

\[ F_{m+1}(x) = F_m(x) + \eta h_m(x) \]

where

  • \(h_m(x)\) predicts the residuals
  • \(\eta\) is the learning rate

This already gives the basic intuition of boosting:

each new tree tries to correct the remaining errors of the current model.

13.5 From residuals to gradients

The residual fitting idea works naturally for squared error loss. However, for more general loss functions, ordinary residuals are no longer appropriate.

Instead, Gradient Boosting uses the negative gradient of the loss function.

Suppose the total loss is

\[ \mathcal L = \sum_{i=1}^n \ell(y_i,F(x_i)). \]

At iteration \(m\), the pseudo-residuals are defined as

\[ r_{im} = - \frac{ \partial \ell(y_i,F(x_i)) }{ \partial F(x_i) } \Bigg|_{F=F_m}. \]

The algorithm becomes:

  1. compute pseudo-residuals
  2. fit a tree to pseudo-residuals
  3. update the model

Therefore the update direction is the direction of steepest decrease of the loss function.

Thus Gradient Boosting can be viewed as

gradient descent in function space.

This is why the method is called Gradient Boosting.

13.6 Why squared error gives ordinary residuals

For squared error loss,

\[ \ell(y,F(x)) = (y-F(x))^2, \]

we compute

\[ \frac{\partial \ell}{\partial F(x)} = -2(y-F(x)). \]

Therefore

$$
=
2(y-F(x)).
$$

Up to a constant factor, the negative gradient is exactly the residual:

\[ r_i = y_i-F(x_i). \]

Thus ordinary residual fitting is a special case of gradient boosting.

13.7 Learning rate and shrinkage

The parameter \(\eta\) is called the learning rate or shrinkage parameter.

The update becomes

\[ F_{m+1}(x) = F_m(x) + \eta h_m(x). \]

Smaller values of \(\eta\):

  • make learning slower
  • usually require more trees
  • often improve generalization
  • reduce overfitting risk

In practice, boosting often works best with:

  • small learning rate
  • many shallow trees

13.8 Why shallow trees are commonly used

Boosting usually uses shallow trees, often with depth between 1 and 8.

There are several reasons:

  • shallow trees are weak learners
  • weak learners reduce overfitting
  • small trees are computationally efficient
  • additive combinations of many small trees can still create highly complex decision boundaries

A depth-1 tree is called a decision stump. AdaBoost commonly uses stumps.

Larger trees can model more complicated interactions, but they also increase the risk of overfitting.

14 AdaBoost, GBDT and XGBoost

With the optimization viewpoint, AdaBoost, Gradient Boosting, and XGBoost can be understood within one unified framework.

All three methods:

  • build additive models
  • train models sequentially
  • reduce errors stage-by-stage
  • combine many weak learners

However, they differ in how the optimization problem is formulated.

14.1 AdaBoost

AdaBoost was originally developed for classification problems.

Instead of directly fitting residuals, AdaBoost increases the weights of misclassified observations.

At iteration \(m\):

  1. fit a weak classifier
  2. increase weights on difficult observations
  3. decrease weights on easy observations
  4. combine classifiers using weighted voting

The final model is

\[ F_M(x) = \sum_{m=1}^M \alpha_m h_m(x). \]

Later research showed that AdaBoost can also be interpreted as minimizing an exponential loss function:

\[ \ell(y,F(x)) = e^{-yF(x)}. \]

This connects AdaBoost to the gradient boosting framework.

14.2 GBDT

GBDT usually refers to:

Gradient Boosted Decision Trees

This is the standard gradient boosting framework where:

  • the weak learners are regression trees
  • optimization is performed using first-order gradients
  • arbitrary differentiable loss functions can be used

Typical losses include:

  • squared error for regression
  • logistic loss for classification
  • Huber loss for robust regression

GBDT is more general than AdaBoost because it directly formulates boosting as an optimization problem.

15 Tree Boosting and XGBoost Training

15.1 Tree Boosting

Suppose our boosted tree model has the form

\[ F_M(x) = \sum_{m=1}^M f_m(x), \]

where each \(f_m(x)\) is a regression tree.

The prediction is obtained by adding together many trees.

Unlike linear regression,

\[ \hat y = \beta_0 + \sum_{j=1}^p \beta_j x_j, \]

boosting does not optimize finitely many parameters directly.

Instead, it optimizes functions.

Each tree contains:

  • tree structure
  • split variables
  • split thresholds
  • leaf values

Therefore the optimization problem is much more difficult.

16 Objective Function

The general objective function is

\[ \mathcal L = \sum_{i=1}^n l(y_i,\hat y_i) + \sum_{m=1}^M \Omega(f_m), \]

where

  • \(l(y_i,\hat y_i)\) is the training loss
  • \(\Omega(f_m)\) is tree regularization

Examples:

  • squared error for regression
  • logistic loss for classification

17 Why Trees Cannot Be Optimized Jointly

For ordinary regression, we optimize a finite-dimensional vector:

\[ (\beta_0,\beta_1,\dots,\beta_p). \]

We can directly compute gradients:

\[ \frac{\partial \mathcal L}{\partial \beta_j}. \]

For trees, however, the parameters include:

  • split variables
  • split locations
  • number of leaves
  • leaf predictions

The structure itself is discrete and combinatorial.

Therefore it is essentially impossible to jointly optimize all trees simultaneously.

18 Additive Training

Boosting uses stagewise additive training.

At iteration \(t\):

  • previous trees are fixed
  • only one new tree is trained

Define

\[ \hat y_i^{(t)} = \sum_{k=1}^t f_k(x_i). \]

Then

\[ \hat y_i^{(t)} = \hat y_i^{(t-1)} + f_t(x_i). \]

So every new tree improves the current model.

19 What Is Actually Trained?

At step \(t\), the ONLY thing being trained is:

\[ f_t(x). \]

The algorithm learns:

  • the tree structure
  • the split positions
  • the leaf scores

for the new tree only.

All old trees remain fixed forever.

20 Residual View for Squared Error

Suppose we use MSE loss:

\[ l(y_i,\hat y_i) = (y_i-\hat y_i)^2. \]

At iteration \(t\):

\[ \mathcal L^{(t)} = \sum_{i=1}^n \left( y_i - (\hat y_i^{(t-1)} + f_t(x_i)) \right)^2. \]

Define residuals:

\[ r_i^{(t)} = y_i-\hat y_i^{(t-1)}. \]

Then

\[ \mathcal L^{(t)} = \sum_{i=1}^n (r_i^{(t)} - f_t(x_i))^2. \]

Therefore:

the new tree is trained to fit the residuals.

This is the original intuition of gradient boosting.

21 General Loss Functions and Taylor Expansion

For logistic loss or ranking loss, the residual form is no longer simple.

XGBoost uses a second-order Taylor expansion.

At iteration \(t\):

\[ \mathcal L^{(t)} = \sum_{i=1}^n l(y_i,\hat y_i^{(t-1)} + f_t(x_i)) + \Omega(f_t). \]

Expand around \(\hat y_i^{(t-1)}\):

\[ l(y_i,\hat y_i^{(t-1)} + f_t(x_i)) \approx l(y_i,\hat y_i^{(t-1)}) + g_i f_t(x_i) + \frac12 h_i f_t(x_i)^2, \]

where

\[ g_i = \frac{\partial l(y_i,\hat y_i^{(t-1)})} {\partial \hat y_i^{(t-1)}}, \]

and

\[ h_i = \frac{\partial^2 l(y_i,\hat y_i^{(t-1)})} {\partial (\hat y_i^{(t-1)})^2}. \]

Here:

  • \(g_i\) = gradient
  • \(h_i\) = Hessian

Removing constants gives:

\[ \tilde{\mathcal L}^{(t)} = \sum_{i=1}^n \left[ g_i f_t(x_i) + \frac12 h_i f_t(x_i)^2 \right] + \Omega(f_t). \]

This is the optimization objective used by XGBoost.

22 Important Interpretation

XGBoost does NOT perform ordinary gradient descent on tree parameters.

Instead it alternates between:

  1. Compute gradients and Hessians
  2. Build a tree that best fits them
  3. Compute optimal leaf values analytically
  4. Add the tree to the ensemble

So XGBoost combines:

  • functional gradient descent
  • greedy tree construction

32 Why Hessians Help

Gradient boosting only uses first derivatives.

XGBoost additionally uses second derivatives:

\[ h_i = \frac{\partial^2 l}{\partial \hat y_i^2}. \]

This gives local curvature information.

It behaves similarly to Newton’s method:

\[ \text{new step} \approx -\frac{\text{gradient}}{\text{curvature}}. \]

Therefore XGBoost is often:

  • faster
  • more stable
  • more accurate

than ordinary gradient boosting.

33 GBDT and XGBoost from the Same Taylor Expansion View

At boosting step \(t\), suppose the current model is

\[ F_{t-1}(x). \]

We add one new tree

\[ f_t(x), \]

so the updated model is

\[ F_t(x) = F_{t-1}(x) + f_t(x). \]

The step-\(t\) objective is

\[ \mathcal L^{(t)} = \sum_{i=1}^n l\left(y_i,F_{t-1}(x_i)+f_t(x_i)\right). \]

The question is:

What should the new tree \(f_t\) fit?

34 1. GBDT: First-Order Taylor Approximation

For GBDT, use the first-order Taylor expansion:

\[ l\left(y_i,F_{t-1}(x_i)+f_t(x_i)\right) \approx l\left(y_i,F_{t-1}(x_i)\right) + g_i f_t(x_i), \]

where

\[ g_i = \left. \frac{\partial l(y_i,F(x_i))} {\partial F(x_i)} \right|_{F=F_{t-1}}. \]

The first term

\[ l\left(y_i,F_{t-1}(x_i)\right) \]

does not depend on the new tree \(f_t\), so it is a constant. After removing constants, we get

\[ \tilde{\mathcal L}^{(t)} \approx \sum_{i=1}^n g_i f_t(x_i). \]

This expression tells us the direction in which the loss changes.

To decrease the loss, we want

\[ f_t(x_i) \]

to go in the opposite direction of \(g_i\).

Thus the desired value is

\[ f_t(x_i) \approx -g_i. \]

Define the pseudo-residual

\[ r_i^{(t)} = -g_i = - \left. \frac{\partial l(y_i,F(x_i))} {\partial F(x_i)} \right|_{F=F_{t-1}}. \]

Therefore GBDT trains the new tree by fitting

\[ (x_i,r_i^{(t)}). \]

That is,

\[ f_t \approx \arg\min_f \sum_{i=1}^n \left( r_i^{(t)}-f(x_i) \right)^2. \]

So in GBDT:

\[ \boxed{ \text{new tree fits } -g_i } \]

35 2. XGBoost: Second-Order Taylor Approximation

XGBoost uses a second-order Taylor expansion:

\[ l\left(y_i,F_{t-1}(x_i)+f_t(x_i)\right) \approx l\left(y_i,F_{t-1}(x_i)\right) + g_i f_t(x_i) + \frac12 h_i f_t(x_i)^2, \]

where

\[ g_i = \left. \frac{\partial l(y_i,F(x_i))} {\partial F(x_i)} \right|_{F=F_{t-1}}, \]

and

\[ h_i = \left. \frac{\partial^2 l(y_i,F(x_i))} {\partial F(x_i)^2} \right|_{F=F_{t-1}}. \]

After removing constants, the approximate objective is

\[ \tilde{\mathcal L}^{(t)} = \sum_{i=1}^n \left[ g_i f_t(x_i) + \frac12 h_i f_t(x_i)^2 \right] + \Omega(f_t). \]

XGBoost uses tree regularization

\[ \Omega(f_t) = \gamma T + \frac12\lambda\sum_{j=1}^T w_j^2, \]

where

  • \(T\) is the number of leaves
  • \(w_j\) is the value of leaf \(j\)
  • \(\gamma\) penalizes the number of leaves
  • \(\lambda\) penalizes large leaf values

Suppose the new tree has leaves

\[ R_1,\dots,R_T. \]

For \(x_i\in R_j\),

\[ f_t(x_i)=w_j. \]

Plug this into the objective:

\[ \tilde{\mathcal L}^{(t)} = \sum_{j=1}^T \sum_{i\in R_j} \left[ g_i w_j + \frac12 h_i w_j^2 \right] + \gamma T + \frac12\lambda\sum_{j=1}^T w_j^2. \]

Group terms by leaf:

\[ \tilde{\mathcal L}^{(t)} = \sum_{j=1}^T \left[ \left(\sum_{i\in R_j}g_i\right)w_j + \frac12 \left(\sum_{i\in R_j}h_i\right)w_j^2 + \frac12\lambda w_j^2 \right] + \gamma T. \]

Define

\[ G_j = \sum_{i\in R_j}g_i, \]

and

\[ H_j = \sum_{i\in R_j}h_i. \]

Then

\[ \tilde{\mathcal L}^{(t)} = \sum_{j=1}^T \left[ G_jw_j + \frac12(H_j+\lambda)w_j^2 \right] + \gamma T. \]

Now minimize with respect to \(w_j\):

\[ \frac{\partial}{\partial w_j} \left[ G_jw_j + \frac12(H_j+\lambda)w_j^2 \right] = G_j+(H_j+\lambda)w_j. \]

Set derivative equal to zero:

\[ G_j+(H_j+\lambda)w_j=0. \]

Therefore

\[ w_j^* = -\frac{G_j}{H_j+\lambda}. \]

That is,

\[ \boxed{ w_j^* = -\frac{\sum_{i\in R_j}g_i} {\sum_{i\in R_j}h_i+\lambda} } \]

So in XGBoost:

\[ \boxed{ \text{new tree uses } g_i,h_i \text{ and assigns Newton-style leaf values} } \]

36 3. Same Logic, Different Taylor Order

Both methods start from

\[ \mathcal L^{(t)} = \sum_{i=1}^n l\left(y_i,F_{t-1}(x_i)+f_t(x_i)\right). \]

GBDT uses

\[ l(y,F+f) \approx l(y,F)+gf. \]

Therefore it follows the negative gradient:

\[ f_t(x_i)\approx -g_i. \]

XGBoost uses

\[ l(y,F+f) \approx l(y,F)+gf+\frac12hf^2. \]

Therefore it solves a local quadratic problem:

\[ \min_w G_jw+\frac12(H_j+\lambda)w^2, \]

which gives

\[ w_j^* = -\frac{G_j}{H_j+\lambda}. \]

37 4. Interpretation

GBDT asks:

\[ \text{Which direction decreases the loss?} \]

Answer:

\[ -g_i. \]

XGBoost asks:

\[ \text{Using both direction and curvature, what is the best local step?} \]

Answer:

\[ -\frac{G_j}{H_j+\lambda}. \]

So the relationship is:

\[ \boxed{ \text{GBDT is first-order boosting} } \]

\[ \boxed{ \text{XGBoost is second-order/Newton boosting} } \]

After removing constants independent of \(f_t\), we get

\[ \tilde{\mathcal L}^{(t)} \approx \sum_{i=1}^n g_i f_t(x_i). \]

Since we want to decrease the loss, the desired direction is

\[ -f_t(x_i) \approx g_i, \]

38 Function Space View

Boosting can be viewed as optimization in function space.

The model evolves as

\[ F_t(x) = F_{t-1}(x) + f_t(x). \]

We are not directly updating finite-dimensional parameters like:

\[ \beta_j \leftarrow \beta_j - \eta \frac{\partial L}{\partial \beta_j}. \]

Instead we update the predictor itself by adding functions.

The basis functions are trees.

Since there are infinitely many possible trees, this is viewed as an infinite-dimensional optimization problem.

38.1 GBDT and Taylor Approximation

GBDT means Gradient Boosted Decision Trees.

The model has the additive form

\[ F_M(x) = \sum_{m=1}^M \eta f_m(x), \]

where each \(f_m(x)\) is a regression tree and \(\eta\) is the learning rate.

The main idea is:

At each step, we add a new tree that reduces the current loss as much as possible.

38.2 1. The objective function

Suppose we have data

\[ (x_1,y_1),\dots,(x_n,y_n). \]

At iteration \(m\), the current model is

\[ F_{m-1}(x). \]

The current prediction for observation \(i\) is

\[ \hat y_i^{(m-1)} = F_{m-1}(x_i). \]

We want to add a new tree \(f_m(x)\), so the new prediction becomes

\[ \hat y_i^{(m)} = \hat y_i^{(m-1)} + f_m(x_i). \]

The new objective is

\[ \mathcal L^{(m)} = \sum_{i=1}^n \ell \left( y_i, \hat y_i^{(m-1)} + f_m(x_i) \right). \]

So the key question is:

How should we choose the next tree \(f_m\)?

38.3 2. First-order idea: fit the negative gradient

For a general loss function, ordinary residuals may not be enough.

So GBDT uses the negative gradient of the loss.

Define

\[ g_i = \frac{ \partial \ell(y_i,\hat y_i) }{ \partial \hat y_i } \Bigg|_{\hat y_i=\hat y_i^{(m-1)}}. \]

Then the negative gradient is

\[ -g_i. \]

GBDT fits the next tree to

\[ -g_i. \]

That is, the new tree \(f_m(x)\) is trained to approximate the negative gradient values

\[ -g_1,\dots,-g_n. \]

This is why GBDT is called gradient boosting.

38.4 3. Why residuals are gradients for squared error

For squared error loss,

\[ \ell(y,\hat y) = \frac12 (y-\hat y)^2. \]

Then

\[ g_i = \frac{\partial}{\partial \hat y_i} \frac12 (y_i-\hat y_i)^2 = \hat y_i-y_i. \]

Therefore

\[ -g_i = y_i-\hat y_i. \]

So for squared error loss, the negative gradient is exactly the residual.

That means:

fitting residuals is a special case of fitting negative gradients.

38.5 4. Taylor polynomial idea

The Taylor polynomial is used to approximate a complicated loss function by a simpler expression around the current prediction.

At iteration \(m\), we already know the current prediction

\[ \hat y_i^{(m-1)}. \]

We want to understand what happens if we add a small correction

\[ f_m(x_i). \]

So we approximate

\[ \ell \left( y_i, \hat y_i^{(m-1)} + f_m(x_i) \right) \]

around

\[ \hat y_i^{(m-1)}. \]

Let

\[ \Delta_i = f_m(x_i). \]

Then Taylor expansion gives

\[ \ell(y_i,\hat y_i^{(m-1)}+\Delta_i) \approx \ell(y_i,\hat y_i^{(m-1)}) + g_i \Delta_i + \frac12 h_i \Delta_i^2, \]

where

\[ g_i = \frac{ \partial \ell(y_i,\hat y_i) }{ \partial \hat y_i } \Bigg|_{\hat y_i=\hat y_i^{(m-1)}} \]

and

\[ h_i = \frac{ \partial^2 \ell(y_i,\hat y_i) }{ \partial \hat y_i^2 } \Bigg|_{\hat y_i=\hat y_i^{(m-1)}}. \]`

Here:

  • \(g_i\) is the first derivative
  • \(h_i\) is the second derivative
  • \(\Delta_i=f_m(x_i)\) is the correction made by the new tree

38.6 5. What the Taylor expansion means

The loss after adding the new tree is approximately

\[ \mathcal L^{(m)} \approx \sum_{i=1}^n \left[ \ell(y_i,\hat y_i^{(m-1)}) + g_i f_m(x_i) + \frac12 h_i f_m(x_i)^2 \right]. \]

The first term

\[ \ell(y_i,\hat y_i^{(m-1)}) \]

does not depend on the new tree \(f_m\).

So when choosing \(f_m\), we can ignore it.

Therefore, the approximate objective becomes

\[ \widetilde{\mathcal L}^{(m)} = \sum_{i=1}^n \left[ g_i f_m(x_i) + \frac12 h_i f_m(x_i)^2 \right]. \]

This is the key point:

Taylor expansion turns the problem of minimizing the original loss into a simpler quadratic approximation.

38.7 6. First-order GBDT versus second-order GBDT

Classical GBDT mainly uses first-order information:

\[ g_i. \]

It fits the next tree to the negative gradient:

\[ -g_i. \]

XGBoost uses second-order information:

\[ g_i \quad\text{and}\quad h_i. \]

So XGBoost chooses trees by minimizing the approximate quadratic objective

\[ \sum_{i=1}^n \left[ g_i f_m(x_i) + \frac12 h_i f_m(x_i)^2 \right]. \]

This is why XGBoost is often described as a second-order gradient boosting method.

38.8 7. How a tree enters the Taylor approximation

A regression tree partitions the feature space into leaves.

Suppose the tree has \(T\) leaves. Each observation is assigned to one leaf.

Let

\[ q(x_i) \]

be the leaf containing \(x_i\).

The tree prediction is

\[ f(x_i) = w_{q(x_i)}, \]

where \(w_j\) is the prediction value assigned to leaf \(j\).

So the tree is determined by:

  1. the tree structure \(q(x)\)
  2. the leaf values \(w_1,\dots,w_T\)

38.9 8. Objective for one fixed tree structure

For a fixed tree structure, define

\[ I_j = \{i:q(x_i)=j\}. \]

This is the set of observations in leaf \(j\).

The approximate objective is

\[ \widetilde{\mathcal L} = \sum_{i=1}^n \left[ g_i f(x_i) + \frac12 h_i f(x_i)^2 \right]. \]

Since \(f(x_i)=w_j\) for all observations in leaf \(j\), we can group terms by leaf:

\[ \widetilde{\mathcal L} = \sum_{j=1}^T \sum_{i\in I_j} \left[ g_i w_j + \frac12 h_i w_j^2 \right]. \]

Define

\[ G_j = \sum_{i\in I_j} g_i \]

and

\[ H_j = \sum_{i\in I_j} h_i. \]

Then

\[ \widetilde{\mathcal L} = \sum_{j=1}^T \left[ G_j w_j + \frac12 H_j w_j^2 \right]. \]

So for each leaf, we only need to optimize

\[ G_j w_j + \frac12 H_j w_j^2. \]

38.10 9. Optimal leaf value

For one leaf, minimize

\[ G_j w_j + \frac12 H_j w_j^2. \]

Take derivative with respect to \(w_j\):

\[ G_j + H_j w_j = 0. \]

Therefore

\[ w_j^* = - \frac{G_j}{H_j}. \]

This is the optimal prediction value for leaf \(j\) under the second-order approximation.

With \(L_2\) regularization, the formula becomes

\[ w_j^* = - \frac{G_j}{H_j+\lambda}. \]

This is one of the most important formulas in XGBoost.

38.11 10. Best score for a leaf

Plugging

\[ w_j^* = - \frac{G_j}{H_j+\lambda} \]

back into the objective gives the best score for leaf \(j\):

\[ -\frac12 \frac{G_j^2}{H_j+\lambda}. \]

So a leaf is good if

\[ \frac{G_j^2}{H_j+\lambda} \]

is large.

Interpretation:

  • large \(G_j\) means the leaf has strong remaining gradient signal
  • large \(H_j\) means the loss is curved strongly there
  • \(\lambda\) shrinks the leaf value and stabilizes the model

38.12 11. Split gain

Suppose a leaf is split into a left child and a right child.

Before the split, the score is

\[ \frac{G^2}{H+\lambda}. \]

After the split, the score is

\[ \frac{G_L^2}{H_L+\lambda} + \frac{G_R^2}{H_R+\lambda}. \]

The split gain is

\[ \text{Gain} = \frac12 \left[ \frac{G_L^2}{H_L+\lambda} + \frac{G_R^2}{H_R+\lambda} - \frac{G^2}{H+\lambda} \right] - \gamma. \]

Here:

  • \(G_L,H_L\) are the gradient and Hessian sums in the left child
  • \(G_R,H_R\) are the gradient and Hessian sums in the right child
  • \(G,H\) are the gradient and Hessian sums before the split
  • \(\gamma\) penalizes adding a new leaf

A split is useful only if the gain is positive.

38.13 12. Why Taylor approximation is useful

The original problem is hard:

\[ \min_f \sum_{i=1}^n \ell(y_i,\hat y_i+f(x_i)). \]

The tree \(f\) is discrete and nonlinear.

Taylor expansion replaces the loss by a local quadratic approximation:

\[ \sum_{i=1}^n \left[ g_i f(x_i) + \frac12 h_i f(x_i)^2 \right]. \]

This makes tree construction much easier because the quality of a leaf or split can be computed using only:

\[ G_j=\sum g_i \]

and

\[ H_j=\sum h_i. \]

So the whole tree-building process becomes:

  1. compute \(g_i\) and \(h_i\)
  2. try possible splits
  3. compute split gain
  4. choose the split with largest gain
  5. repeat

38.14 13. Example: squared error loss

For squared error loss,

\[ \ell(y,\hat y) = \frac12(y-\hat y)^2. \]

The first derivative is

\[ g_i = \hat y_i-y_i. \]

The second derivative is

\[ h_i = 1. \]

Therefore

\[ G_j = \sum_{i\in I_j} (\hat y_i-y_i) \]

and

\[ H_j = |I_j|. \]

The optimal leaf value is

\[ w_j^* = - \frac{G_j}{H_j} = \frac{ \sum_{i\in I_j}(y_i-\hat y_i) }{ |I_j| }. \]

So for squared error loss, the leaf value is simply the average residual in that leaf.

This matches the ordinary residual-fitting intuition.

38.15 14. Example: logistic loss

For binary classification, we often use logistic loss.

Let

\[ p_i = P(y_i=1|x_i). \]

The model output is usually a score

\[ \hat y_i = F(x_i), \]

and the probability is

\[ p_i = \frac{1}{1+e^{-F(x_i)}}. \]

For logistic loss, the derivatives are

\[ g_i = p_i-y_i \]

and

\[ h_i = p_i(1-p_i). \]

Thus the new tree is built using:

\[ G_j = \sum_{i\in I_j}(p_i-y_i) \]

and

\[ H_j = \sum_{i\in I_j}p_i(1-p_i). \]

The optimal leaf value is

\[ w_j^* = - \frac{ \sum_{i\in I_j}(p_i-y_i) }{ \sum_{i\in I_j}p_i(1-p_i)+\lambda }. \]

This is similar to a Newton step for logistic regression.

38.16 15. Big picture

GBDT can be understood in three levels.

38.16.1 Level 1: residual fitting

For squared error loss, each new tree fits the residuals:

\[ r_i = y_i-\hat y_i. \]

38.16.2 Level 2: gradient boosting

For general loss functions, each new tree fits the negative gradient:

\[ -g_i. \]

38.16.3 Level 3: second-order boosting

XGBoost uses both first and second derivatives:

\[ g_i \quad\text{and}\quad h_i. \]

Taylor approximation gives a local quadratic objective, allowing the algorithm to compute:

  • optimal leaf values
  • split gains
  • regularized tree scores

38.17 16. Summary

Note

GBDT builds an additive model of trees. At each step, it adds a new tree to reduce the current loss.

For squared error loss, this means fitting residuals.

For general differentiable losses, this means fitting negative gradients.

XGBoost goes further by using a second-order Taylor approximation of the loss. This converts the original loss into a local quadratic objective, making it possible to compute optimal leaf values and split gains using gradient sums and Hessian sums.

38.18 XGBoost

XGBoost stands for:

eXtreme Gradient Boosting

XGBoost extends GBDT with several important improvements.

The major idea is:

use more advanced optimization and stronger regularization.

38.19 Second-order approximation

Standard GBDT uses only first-order gradient information.

XGBoost additionally uses second-order derivatives.

Suppose the objective is

\[ \mathcal L = \sum_{i=1}^n \ell(y_i,\hat y_i). \]

At iteration \(m\), XGBoost approximates the loss using a second-order Taylor expansion:

\[ \ell(y_i,\hat y_i + f(x_i)) \approx \ell(y_i,\hat y_i) + g_i f(x_i) + \frac12 h_i f(x_i)^2 \]

where

\[ g_i = \frac{\partial \ell(y_i,\hat y_i)}{\partial \hat y_i} \]

and

\[ h_i = \frac{\partial^2 \ell(y_i,\hat y_i)}{\partial \hat y_i^2}. \]

Using second-order information often gives:

  • faster optimization
  • more accurate split evaluation
  • improved numerical stability

38.20 Regularization in XGBoost

XGBoost also places strong emphasis on regularization.

The objective becomes

\[ \mathcal L = \sum_{i=1}^n \ell(y_i,\hat y_i) + \Omega(f). \]

A common regularization term is

\[ \Omega(f) = \gamma T + \frac12 \lambda \sum_{j=1}^T w_j^2 \]

where

  • \(T\) is the number of leaves
  • \(w_j\) are leaf weights
  • \(\gamma\) penalizes large trees
  • \(\lambda\) controls leaf weight shrinkage

This helps:

  • reduce overfitting
  • stabilize optimization
  • improve generalization

38.21 Additional improvements in XGBoost

XGBoost also includes many engineering optimizations:

  • parallel computation
  • efficient split search
  • sparse feature handling
  • missing value handling
  • column subsampling
  • row subsampling
  • cache-aware computation

These improvements make XGBoost both:

  • statistically powerful
  • computationally efficient

All three methods are additive sequential learning algorithms based on weak learners.

38.23 Gradient Boosting: optimization view

The core idea of boosting is to sequentially train models in order to fix the errors from the earlier versions of the models. Therefore a naive idea is to train models to fit the residuals. This is gradient boosting. In this section we first consider regression problems.

Gradient boosting builds a model of the form

\[ F_M(x) = \sum_{m=1}^M \beta_m h_m(x) \]

where

  • \(h_m(x)\) is usually a small regression tree
  • \(\beta_m\) is a coefficient
  • the model is built sequentially

Suppose we want to minimize squared error loss

\[ L(y,F(x)) = (y-F(x))^2 \]

Suppose the current model is \(F_m(x)\).

The residuals are

\[ r_i = y_i-F_m(x_i) \]

A natural idea is:

  1. compute residuals
  2. fit a new tree to residuals
  3. add this tree to the model

Then we update

\[ F_{m+1}(x) = F_m(x) + \eta h_m(x) \]

where

  • \(h_m(x)\) predicts residuals
  • \(\eta\) is the learning rate

This already gives the basic intuition of boosting.

Instead of ordinary residuals, we compute the negative gradient of the loss function.

For a general loss function

\[ \mathcal L = \sum_{i=1}^n \ell(y_i,F(x_i)) \]

the pseudo-residuals are

\[ r_{im} = - \frac{ \partial \ell(y_i,F(x_i)) }{ \partial F(x_i) } \Bigg|_{F=F_m} \]

Then we:

  1. compute pseudo-residuals
  2. fit a tree to pseudo-residuals
  3. update the model

Thus Gradient Boosting can be viewed as:

gradient descent in function space.

This is why the method is called Gradient Boosting.

41.1.2 Step 2: Repeat for \(m=1,\dots,M\)

41.1.2.1 Compute pseudo-residuals

\[ r_{im} = - \frac{ \partial \ell(y_i,F(x_i)) }{ \partial F(x_i) } \Bigg|_{F=F_m} \]

41.1.2.2 Fit tree \(h_m(x)\) to pseudo-residuals

41.1.2.3 Update the model

\[ F_{m+1}(x) = F_m(x) + \eta h_m(x) \]

41.1.3 Step 3: Output final model

\[ F_M(x) \]

42 Why Shallow Trees?

Gradient Boosting usually uses shallow trees:

  • depth 1: stumps
  • depth 2–8: common in practice

Small trees behave as weak learners.

This helps:

  • regularization
  • stability
  • smoother fitting
  • better generalization

Deep trees can fit residual noise very aggressively.

43 Why Deep Trees Overfit in Boosting

Boosting already reduces bias very effectively.

Later trees are fitted to increasingly small residual patterns. Eventually many residuals mainly contain noise.

If trees are very deep:

  • they can memorize residual noise
  • overfitting accumulates sequentially
  • later trees amplify previous overfitting

This differs from Random Forests.

43.1 Random Forest

Random Forest uses:

  • deep high-variance trees
  • averaging to reduce variance

Therefore deep trees are often beneficial.

43.2 Boosting

Boosting uses:

  • sequential correction
  • additive fitting

Thus:

  • deep trees can overfit very quickly
  • shallow trees act as regularization

This is one reason boosting typically prefers shallow trees.

44 Learning Rate

The learning rate \(\eta\) is one of the most important hyperparameters.

The update formula is

\[ F_{m+1}(x) = F_m(x) + \eta h_m(x) \]

Small \(\eta\) means:

  • slower learning
  • more trees required
  • often better generalization

Typical values:

  • 0.1
  • 0.05
  • 0.01

This is also called shrinkage.

46 Gradient Boosting for Classification

For classification, boosting usually minimizes logistic loss instead of squared error.

Binary logistic loss:

\[ \ell(y,F) = \log(1+e^{-yF}) \]

The final score function \(F(x)\) is converted into probabilities using the logistic function:

\[ p(x) = \frac{1}{1+e^{-F(x)}} \]

Thus boosting naturally produces:

  • class labels
  • probabilities
  • confidence scores

47 Relationship with AdaBoost

AdaBoost can actually be viewed as a special case of Gradient Boosting.

AdaBoost minimizes exponential loss:

\[ \ell(y,F) = e^{-yF} \]

Gradient Boosting generalizes this idea to arbitrary differentiable loss functions.

Historically, this was an important breakthrough because it unified boosting under optimization theory.

48 Margin Interpretation

For classification, boosting models produce a score function \(F(x)\).

The quantity

\[ yF(x) \]

is called the margin.

  • positive margin: correct prediction
  • negative margin: incorrect prediction
  • large positive margin: confident prediction

Margin theory historically helped explain AdaBoost’s surprisingly good generalization behavior.

However, in modern boosting practice, the optimization and loss-minimization viewpoint is usually more central than margin theory.

49 XGBoost

49.1 Main Idea

XGBoost stands for Extreme Gradient Boosting.

It is essentially:

a highly optimized and regularized implementation of gradient boosting trees.

Main improvements include:

  • second-order optimization
  • explicit regularization
  • efficient tree construction
  • subsampling
  • sparsity handling
  • parallel implementation

50 Objective Function

XGBoost minimizes

\[ \mathcal L = \sum_{i=1}^n \ell(y_i,\hat y_i) + \sum_{m=1}^M \Omega(f_m) \]

where

  • \(\ell\) is the loss function
  • \(\Omega\) regularizes tree complexity

Regularization may penalize:

  • number of leaves
  • leaf weights
  • tree depth

This makes XGBoost more stable than classical boosting.

51 Second-Order Approximation

Classical Gradient Boosting mainly uses first-order gradients.

XGBoost additionally uses second derivatives.

Using Taylor expansion:

\[ \ell(y_i,F+h) \approx \ell(y_i,F) + g_i h + \frac12 h_i h^2 \]

where

\[ g_i = \frac{\partial \ell}{\partial F} \]

and

\[ h_i = \frac{\partial^2 \ell}{\partial F^2} \]

This produces a Newton-style boosting algorithm.

Advantages include:

  • faster convergence
  • better optimization
  • more accurate split evaluation

52 Regularization in XGBoost

Unlike classical boosting, XGBoost explicitly regularizes trees.

Common regularization methods include:

  • tree depth penalties
  • leaf penalties
  • shrinkage
  • row subsampling
  • column subsampling

Thus XGBoost combines:

  • boosting
  • regularization
  • optimization
  • systems engineering

53 Why XGBoost Became Popular

XGBoost became extremely successful because it provides:

  • strong predictive performance
  • fast computation
  • robust regularization
  • scalable training
  • excellent performance on tabular data

For structured tabular datasets, boosted trees often outperform neural networks.

Early stopping is often extremely important in boosting.

59.1 Gradient Boosting

AdaBoost is one form of boosting. Modern boosting methods are usually based on gradient boosting.

The key idea is:

Fit each new learner to the direction that most improves the loss function.

For regression with squared error loss, this becomes especially simple. Each new tree is fit to the residuals of the current model.

Suppose we want to minimize

\[ L(y,F(x)) = \frac12(y-F(x))^2. \]

Start with a simple model:

\[ F_0(x)=\bar y. \]

At round \(m\), compute residuals

\[ r_i^{(m)} = y_i-F_{m-1}(x_i). \]

Fit a regression tree \(h_m(x)\) to these residuals. Then update the model:

\[ F_m(x) = F_{m-1}(x) + \eta h_m(x). \]

Here \(\eta\) is the learning rate.

Thus, for squared error loss, gradient boosting repeatedly fits trees to what remains unexplained.

59.1.1 Gradient View

For a general loss function \(L(y,F(x))\), the residual idea becomes a gradient idea.

At round \(m\), define pseudo-residuals

\[ r_i^{(m)} = - \left[ \frac{\partial L(y_i,F(x_i))}{\partial F(x_i)} \right]_{F=F_{m-1}}. \]

The new tree is fit to these pseudo-residuals. This is why the method is called gradient boosting: it moves the function estimate in the negative gradient direction.

59.1.2 Shrinkage

The learning rate \(\eta\) is also called shrinkage.

A small learning rate means each tree makes only a small correction. This usually requires more trees, but it often improves generalization.

A large learning rate means each tree makes a larger correction. This may learn quickly, but it can overfit.

59.1.3 Tree Depth and Interactions

The depth of each tree controls the interaction order.

A stump can only make one split, so it mainly captures main effects. A depth-2 tree can represent simple interactions. A deeper tree can represent more complex interactions.

In gradient boosting, trees are often shallow. The model becomes flexible by adding many shallow trees rather than by growing one very deep tree.

59.2 XGBoost

XGBoost stands for extreme gradient boosting.

It is a highly optimized and regularized implementation of gradient boosting. XGBoost became popular because it combines strong predictive performance with several practical regularization tools.

Important ideas in XGBoost include:

  • gradient-based sequential tree fitting,
  • learning rate shrinkage,
  • tree depth control,
  • row subsampling,
  • column subsampling,
  • regularization of leaf weights and tree complexity.

59.2.2 Tuning XGBoost

The hyperparameters work together.

A common strategy is:

  1. Start with shallow trees, such as max_depth=2 or max_depth=3.
  2. Use a small learning rate, such as 0.03 or 0.05.
  3. Use enough trees to let the model learn.
  4. Add subsampling to reduce overfitting.
  5. Tune regularization if the model still overfits.

59.2.3 Early Stopping

Boosting can overfit if too many trees are added. Early stopping monitors validation performance and stops when the validation score no longer improves.

Conceptually:

  1. Split the training data into a training part and a validation part.
  2. Fit trees sequentially.
  3. Track validation error after each round.
  4. Stop when validation error stops improving.

In XGBoost, early stopping is often used through an evaluation set.

xgb.fit(
    X_train,
    y_train,
    eval_set=[(X_valid, y_valid)],
    verbose=False,
)

Exact early-stopping syntax can differ across XGBoost versions, so it is useful to check the installed version when writing production code.

59.5 Summary

AdaBoost:

  • builds weak learners sequentially,
  • increases weights on misclassified observations,
  • combines weak learners by weighted voting,
  • can be understood through margins,
  • is sensitive to noisy labels and outliers.

Gradient boosting:

  • fits each new tree to residuals or negative gradients,
  • works with many loss functions,
  • usually uses shallow trees,
  • relies heavily on learning rate, number of trees, and tree depth.

XGBoost:

  • is a regularized and optimized gradient boosting implementation,
  • adds row and column subsampling,
  • includes regularization for tree complexity and leaf weights,
  • is often very strong on tabular data,
  • requires careful tuning.

The key distinction from bagging and random forests is that boosting is sequential. Each new tree depends on the current model and is trained to improve what remains unexplained.
