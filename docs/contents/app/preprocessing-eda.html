Appendix E — Data Processing and EDA

This note uses the synthetic dataset minidataset.csv to demonstrate essential data-processing and EDA operations. The dataset contains repeated measurements from several individuals, each with up to three visits. Each row represents one visit for one individual.

This note provides brief examples rather than comprehensive instructions for each command. If you choose to use a command in your project, consult its documentation and make sure you apply it appropriately to your data and analysis.

E.3 Avoid data leakage

To keep all visits from the same individual together, there are at least two different methods:

  1. Reshape the data so that all visits from the same individual appear in one row (using the method mentioned above), and then split by rows.
  2. Split the unique IDs and then select their rows.
from sklearn.model_selection import train_test_split

ids = df["id"].drop_duplicates()

train_ids, remaining_ids = train_test_split(ids, test_size=0.40, random_state=1)
val_ids, test_ids = train_test_split(remaining_ids, test_size=0.50, random_state=1)

train_df = df.loc[df["id"].isin(train_ids)].copy()
val_df = df.loc[df["id"].isin(val_ids)].copy()
test_df = df.loc[df["id"].isin(test_ids)].copy()

For missing values, we could either drop them

df_dropped = df.dropna()
Caution

Be careful: dropna() removes every row that contains at least one missing value.

Alternatively, we could use fillna() to replace missing values with a specified value, such as \(0\):

df_filled_0 = df.fillna(0)

or we could use fillna() to replace missing values with the column mean:

df_filled = df.copy()
df_filled["num_3"] = df_filled["num_3"].fillna(df_filled["num_3"].mean())

Missing values can also be filled with the mean of each group. This example uses the mean within each cat_1 group:

df_group_filled = df.copy()
group_mean = df.groupby("cat_1")["num_3"].transform("mean")
df_group_filled["num_3"] = df_group_filled["num_3"].fillna(group_mean)
NoteImputer

The examples above show simple approaches to missing-value imputation. A more complete, cross-validation-safe approach typically combines a sklearn imputer with ColumnTransformer and Pipeline, so that imputation is fitted separately within each training fold and applied consistently to other data. The details of this approach are beyond the scope of this note.

E.5 Construct features

Sort by individual and time before calculating within-person differences:

df_sort = df.sort_values(["id", "time"]).copy()

df_sort["time_change"] = df_sort.groupby("id")["time"].diff()
df_sort["num_2_change"] = df_sort.groupby("id")["num_2"].diff()
df_sort["num_2_change_per_day"] = df_sort["num_2_change"] / (df_sort["time_change"])

E.6 Combine numerical values into groups

Use pd.cut() when predefined, ordered intervals have a meaningful interpretation:

df["num_1_group"] = pd.cut(
    df["num_1"],
    bins=[float("-inf"), 45, 55, 65, float("inf")],
    labels=["below_45", "45-54", "55-64", "65_or_above"],
    right=False,
    ordered=True,
)
