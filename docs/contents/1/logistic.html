Logistic regression is a classification method for binary outcomes. It models the conditional probability of one class as a function of the predictors.

For a binary response, write

\[ Y\in\{0,1\}. \]

The goal is to estimate

\[ \Prob(Y=1\mid X=x). \]

This probability can then be used for two tasks:

  • probability estimation,
  • classification by thresholding the probability.

7.1 Modeling Binary Outcomes

In linear regression, we model a quantitative response by

\[ Y=\beta_0+\beta_1x_1+\cdots+\beta_px_p+\epsilon. \]

This is not appropriate for a binary response. A linear model can produce fitted values below 0 or above 1, so its fitted values cannot always be interpreted as probabilities.

Logistic regression instead models

\[ \pi(x) = \Prob(Y=1\mid X=x) \]

using the logistic function:

\[ \pi(x) = \frac{ \exp(\beta_0+\beta_1x_1+\cdots+\beta_px_p) }{ 1+\exp(\beta_0+\beta_1x_1+\cdots+\beta_px_p) }. \]

Let

\[ \eta(x)=\beta_0+\beta_1x_1+\cdots+\beta_px_p. \]

Then

\[ \pi(x)=\frac{e^{\eta(x)}}{1+e^{\eta(x)}}. \]

This always lies between 0 and 1.

NoteMain idea

Logistic regression is linear in the log-odds, not in the probability.

7.2 Odds and the Logit Link

The odds of class 1 are

\[ \frac{\pi(x)}{1-\pi(x)}. \]

For logistic regression,

\[ 1-\pi(x) = \frac{1}{1+e^{\eta(x)}}. \]

Therefore

\[ \frac{\pi(x)}{1-\pi(x)} = e^{\eta(x)}. \]

Taking logs gives

\[ \log\left( \frac{\pi(x)}{1-\pi(x)} \right) = \eta(x) = \beta_0+\beta_1x_1+\cdots+\beta_px_p. \]

The function

\[ \log\left(\frac{p}{1-p}\right) \]

is called the logit function. Logistic regression is a generalized linear model with a Bernoulli response and logit link.

7.3 Interpreting Coefficients

The coefficients are interpreted through odds ratios.

Suppose all predictors except \(x_j\) are fixed. If \(x_j\) increases by one unit, then the log-odds increase by

\[ \beta_j. \]

Exponentiating gives

\[ \text{odds ratio}=e^{\beta_j}. \]

Thus:

  • \(\beta_j\) is the change in log-odds for a one-unit increase in \(x_j\);
  • \(e^{\beta_j}\) is the multiplicative change in the odds.
CautionNot a probability change

A logistic regression coefficient is not a direct change in probability. The probability change depends on the current value of all predictors.

For example, if \(\beta_j=0.05\), then

\[ e^{0.05}\approx 1.051. \]

Holding other predictors fixed, a one-unit increase in \(x_j\) multiplies the odds by about \(1.051\), or increases the odds by about \(5.1\%\).

7.4 From Probability to Classification

After fitting the model, the estimated probability is

\[ \hat\pi(x)=\widehat{\Prob}(Y=1\mid X=x). \]

A common classification rule is

\[ \hat Y = \begin{cases} 1, & \hat\pi(x)>0.5,\\ 0, & \hat\pi(x)\le 0.5. \end{cases} \]

The threshold does not have to be 0.5. If false positives and false negatives have different costs, the threshold should reflect those costs.

7.5 A One-Variable Calculation

Suppose the fitted model is

\[ \log\left(\frac{\pi(x)}{1-\pi(x)}\right) = -3.006+0.052x. \]

For a subject with \(x=55\),

\[ \eta(55) = -3.006+0.052(55) = -0.146. \]

The estimated probability is

\[ \pi(55) = \frac{e^{-0.146}}{1+e^{-0.146}} \approx 0.463. \]

So the model estimates a class-1 probability of about \(46.3\%\).

7.6 Estimation by Maximum Likelihood

For observation \(i\), let

\[ \pi_i=\pi(x_i). \]

Since \(Y_i\) is binary,

\[ Y_i\mid X_i=x_i \sim \operatorname{Bernoulli}(\pi_i). \]

The probability mass function is

\[ \Prob(Y_i=y_i\mid X_i=x_i) = \pi_i^{y_i}(1-\pi_i)^{1-y_i}. \]

For independent observations, the likelihood is

\[ L(\beta) = \prod_{i=1}^n \pi_i^{y_i}(1-\pi_i)^{1-y_i}. \]

The log-likelihood is

\[ \ell(\beta) = \sum_{i=1}^n \left[ y_i\log(\pi_i) + (1-y_i)\log(1-\pi_i) \right]. \]

Using the logistic form, this can be written as

\[ \ell(\beta) = \sum_{i=1}^n \left[ y_i x_i^\top\beta - \log\{1+\exp(x_i^\top\beta)\} \right]. \]

Logistic regression does not have the same closed-form solution as ordinary least squares. The coefficients are found by numerical optimization, commonly Newton-type methods.

7.7 Deviance

In logistic regression and other generalized linear models, deviance measures lack of fit.

Two common quantities are:

  • null deviance: deviance for an intercept-only model;
  • residual deviance: deviance for the fitted model.

A large reduction from null deviance to residual deviance means the predictors explain useful information about the class probabilities.

7.11 Scaling and Pipelines

For unpenalized logistic regression, scaling does not change the fitted probabilities except for numerical details. For penalized logistic regression, scaling is important because the penalty is applied to coefficients.

The usual predictive workflow uses a pipeline.

from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import cross_val_score

pipe = Pipeline(
    steps=[
        ("scaler", StandardScaler()),
        ("model", LogisticRegression(max_iter=1000)),
    ]
)

scores = cross_val_score(
    pipe,
    cancer.data,
    cancer.target,
    cv=5,
    scoring="accuracy",
)

scores.mean()
np.float64(0.9806862288464524)

This fits the scaler inside each training fold, avoiding data leakage.

7.12 Penalized Logistic Regression

Logistic regression can be regularized just like linear regression. The common penalties are:

  • ridge penalty: shrinks coefficients toward zero;
  • lasso penalty: can set some coefficients exactly to zero;
  • elastic net penalty: combines ridge and lasso.

In sklearn, the parameter C controls regularization strength:

\[ C=\frac{1}{\lambda}. \]

Smaller C means stronger regularization.

from sklearn.model_selection import GridSearchCV

pipe = Pipeline(
    steps=[
        ("scaler", StandardScaler()),
        (
            "model",
            LogisticRegression(
                penalty="l1",
                solver="liblinear",
                max_iter=1000,
            ),
        ),
    ]
)

param_grid = {
    "model__C": np.logspace(-3, 2, 20),
}

grid = GridSearchCV(
    pipe,
    param_grid=param_grid,
    cv=5,
    scoring="accuracy",
)

grid.fit(cancer.data, cancer.target)

7.13 Evaluation Metrics

Accuracy is simple, but it can be misleading when classes are imbalanced.

Common metrics include:

  • accuracy,
  • sensitivity or recall,
  • specificity,
  • precision,
  • F1 score,
  • ROC AUC,
  • log loss.
from sklearn.metrics import classification_report, roc_auc_score, log_loss

pipe = Pipeline(
    steps=[
        ("scaler", StandardScaler()),
        ("model", LogisticRegression(max_iter=1000)),
    ]
)

pipe.fit(X_train, y_train)

pred = pipe.predict(X_test)
prob = pipe.predict_proba(X_test)[:, 1]

print(classification_report(y_test, pred))
print("ROC AUC:", roc_auc_score(y_test, prob))
print("Log loss:", log_loss(y_test, prob))

7.14 Summary

Logistic regression:

  • models binary outcomes through class probabilities;
  • uses the logit link to make log-odds linear in the predictors;
  • estimates coefficients by maximum likelihood;
  • interprets coefficients through odds ratios;
  • produces both probabilities and class predictions;
  • has a linear decision boundary in the original predictors;
  • is often combined with regularization in predictive workflows.

Use statsmodels when inference and coefficient tables are the main goal. Use sklearn when prediction, pipelines, and cross-validation are the main goal.
