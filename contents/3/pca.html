Principal component analysis (PCA) is a dimension reduction method. It finds directions that capture the largest variation in the data.

PCA is often used before clustering because it gives a low-dimensional view of high-dimensional observations. It is also useful as a preprocessing step when many variables are correlated.

13.1 The Main Idea

Suppose \(X\) is a centered data matrix with \(n\) observations and \(p\) variables.

The first principal component direction is the unit vector \(v_1\) that maximizes the variance of the projected data:

\[ v_1 = \argmax_{\|v\|=1} \operatorname{Var}(Xv). \]

The first principal component scores are

\[ Xv_1. \]

The second principal component direction is the next highest-variance direction subject to being orthogonal to the first. The later components are defined similarly.

NotePCA in one sentence

PCA rotates the coordinate system so that the first few axes capture as much variation as possible.

13.2 A Two-Dimensional Example

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

from sklearn.decomposition import PCA

rng = np.random.default_rng(1)

Sigma = np.array(
    [
        [0.5, -0.65],
        [-0.65, 1.0],
    ]
)

X_original = rng.multivariate_normal(mean=[1, 2], cov=Sigma, size=100)
X_centered = X_original - X_original.mean(axis=0)

pca = PCA(n_components=2)
scores = pca.fit_transform(X_centered)

pca.components_
array([[-0.58619037,  0.81017334],
       [ 0.81017334,  0.58619037]])

The rows of pca.components_ are the principal component directions.

plt.figure(figsize=(6, 6))
plt.scatter(X_centered[:, 0], X_centered[:, 1], alpha=0.7)
plt.axhline(0, color="black", linewidth=1)
plt.axvline(0, color="black", linewidth=1)

origin = np.array([[0, 0], [0, 0]])
directions = pca.components_
scales = np.sqrt(pca.explained_variance_)

plt.quiver(
    origin[:, 0],
    origin[:, 1],
    directions[:, 0] * scales,
    directions[:, 1] * scales,
    angles="xy",
    scale_units="xy",
    scale=1,
    color=["C1", "C3"],
)

plt.xlabel("x1")
plt.ylabel("x2")
plt.title("Principal Component Directions")
plt.axis("equal")
plt.show()

The first direction follows the main spread of the data. The second direction is orthogonal to the first and captures the remaining variation.

13.3 SVD View

If the centered data matrix has singular value decomposition

\[ X=UDV^\top, \]

then the columns of \(V\) are the principal component directions.

The projected data are

\[ XV=UD. \]

The singular values in \(D\) determine how much variance each component explains.

PCA can also be viewed as an eigen-decomposition of the covariance matrix. When \(X\) is centered,

\[ X^\top X = V D^2 V^\top. \]

Thus the principal component directions are eigenvectors of the covariance matrix.

13.4 Centering and Scaling

PCA should be performed on centered data. If the data are not centered, the first component can be influenced by the location of the data rather than the direction of variation.

Whether to scale variables to unit variance depends on the application.

  • Use scaling when variables are measured in different units.
  • Avoid scaling when variables are already comparable and larger variance itself may be meaningful.
CautionScaling issue

PCA is sensitive to scale. A variable with a large numerical scale can dominate the first principal component.

13.5 PCA on Iris Data

We now apply PCA to the iris data. Since the four variables are measured in centimeters but have different spreads, we standardize before PCA.

from sklearn.datasets import load_iris
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import Pipeline

iris = load_iris(as_frame=True)

X_iris = iris.data
y_iris = iris.target

pca_pipe = Pipeline(
    steps=[
        ("scaler", StandardScaler()),
        ("pca", PCA(n_components=4)),
    ]
)

X_pca = pca_pipe.fit_transform(X_iris)
pca = pca_pipe.named_steps["pca"]

pca.explained_variance_ratio_
array([0.72962445, 0.22850762, 0.03668922, 0.00517871])

Plot the first two principal components.

plt.figure(figsize=(6, 5))
plt.scatter(X_pca[:, 0], X_pca[:, 1], c=y_iris, edgecolor="k")
plt.xlabel("PC1")
plt.ylabel("PC2")
plt.title("Iris PCA")
plt.show()

The species labels are not used by PCA. They are shown only to help interpret the visualization.

13.6 Explained Variance

The explained variance ratio shows how much variation each component captures.

plt.figure(figsize=(6, 4))
plt.plot(
    np.arange(1, len(pca.explained_variance_ratio_) + 1),
    np.cumsum(pca.explained_variance_ratio_),
    marker="o",
)
plt.xlabel("number of components")
plt.ylabel("cumulative explained variance")
plt.title("PCA Explained Variance")
plt.ylim(0, 1.05)
plt.show()

The cumulative curve helps decide how many components are needed to retain most of the variation.

13.7 Loadings

The loadings describe how original variables contribute to each principal component.

    columns=[f"PC{i}" for i in range(1, 5)],
)

13.8 PCA and Clustering

PCA is not a clustering method. It does not assign observations to groups.

However, PCA is often useful before clustering because:

  • it reveals low-dimensional structure,
  • it can reduce noise,
  • it can make cluster plots easier to interpret,
  • it can reduce the number of variables before applying k-means or hierarchical clustering.
CautionPCA can hide clusters

PCA preserves directions of largest variance. If cluster separation occurs in a low-variance direction, the first few PCs may not show it.

13.9 Summary

PCA:

  • is a linear dimension reduction method,
  • finds orthogonal directions of maximum variation,
  • is usually performed after centering,
  • may require scaling,
  • produces scores for observations and loadings for variables,
  • is useful for visualization and preprocessing before clustering.
